# ۰۴ — رشته‌ها و Sliceها

طبق گفته‌ها و تو عمل، این تنها موضوعیه که تو همون اول کار، بیشتر از همه باعث زمین‌خوردن و سردرگمی برنامه‌نویس‌های پایتون می‌شه: زبان Rust (حداقل) دو تا نوعِ رشته (string) داره، و این دوتا بی‌دلیل هم ساخته نشدن؛ وجودشون دقیقاً به مباحث مالکیت (ownership) و قرض‌گرفتن (borrowing) که تو دوتا ماژول قبلی یاد گرفتیم گره خورده. مفهومِ برش‌ها (Slices) همون ایده‌ی رشته‌ها رو برای هر دنباله‌ای (sequence) تعمیم می‌ده، نه فقط برای متن.
