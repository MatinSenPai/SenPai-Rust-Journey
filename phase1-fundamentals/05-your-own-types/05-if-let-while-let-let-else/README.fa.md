# ۰۵.۳ — ساختارهای `if let` / `while let`

## وقتی نوشتن یه `match` کامل زیاده‌رویه

```rust
let maybe_rating: Option<u8> = Some(9);

// استفاده از match کامل، وقتی که تو واقعاً فقط به یک حالت خاص اهمیت می‌دی:
match maybe_rating {
    Some(r) => println!("rated {r}/10"),
    None => {}
}

// دقیقاً همون کار، با روشی خیلی مستقیم‌تر:
if let Some(r) = maybe_rating {
    println!("rated {r}/10");
}
```

عبارتِ `{ ... } if let PATTERN = value` اون بلاک کد رو فقط تو صورتی اجرا می‌کنه که متغیرِ `value` با `PATTERN` همخونی داشته باشه و همزمان هر داده‌ای که تو الگو اسیر (capture) شده رو هم بیرون می‌کشه — در واقع این یه `match` هست که تو فقط به یک دونه از بازوهاش اهمیت دادی و بقیه رو با یه خطای سکوت (fallback) که هیچ کاری نمی‌کنه نادیده گرفتی. هر وقت لازم بود تمام حالت‌ها رو هندل کنی برو سراغ `match`؛ اما هر وقت از ته دلت فقط یه حالت خاص برات مهم بود و می‌خواستی بقیه رو بی‌خیال بشی برو سراغ `if let`.

ضمن اینکه `if let` می‌تونه با خودش یه `else` هم داشته باشه:

```rust
if let Some(r) = maybe_rating {
    println!("rated {r}/10");
} else {
    println!("not rated yet");
}
```

## عبارت `while let` — تا زمانی که الگو مچ (match) می‌شه، به چرخیدن ادامه بده

```rust
let mut stack = vec![1, 2, 3];
while let Some(top) = stack.pop() {
    println!("popped {top}");
}
// این حلقه اول ۳، بعد ۲ و بعد ۱ رو چاپ می‌کنه، و وقتی ()stack.pop
// مقدار None رو برگردوند خودش متوقف می‌شه
```

متد `Vec::pop` آخرین عضو وکتور رو پاک می‌کنه و به شکل `Some(T)` برمی‌گردونتش، یا اگه وکتور خالی شده باشه `None` می‌ده. دستور `()while let Some(top) = stack.pop` دقیقاً تا زمانی که اون الگو مچ می‌شه، به تکرار ادامه میده — این یه راه خیلی مرسوم واسه خالی‌کردنِ (drain) یه مجموعه‌ست، یا کلاً کارهایی که شکلشون اینطوریه: «همینجوری هی مقادیر `Some` رو بکش بیرون تا زمانی که به `None` بخوری.»
