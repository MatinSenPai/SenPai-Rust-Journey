# ایست بازرسی

1. بلوک تابع `moved_value_demo` را فعال کن و `cargo check -p p1-02-01-move-semantics` را اجرا کن. کد دقیق خطا، مثل `E0382`، را بنویس و با زبان خودت توضیح بده. سپس بلوک را دوباره comment کن.
2. تابع `reclaim_and_extend` یک `s: String` می‌گیرد و `String` برمی‌گرداند. چرا باید `s` را برگرداند؟ اگر خروجی `()` بود، فراخوان چه دسترسی‌ای را از دست می‌داد؟
3. تابع `total_length` یک `Vec<String>` می‌گیرد، نه `&Vec<String>`. پس از `total_length(strings)` آیا `strings` در فراخوان معتبر است؟ چرا تمرین عمداً مالکیت کامل بردار را می‌گیرد؟
4. در Python چه چیزی به «این متغیر از این خط به بعد معتبر نیست» نزدیک است؟ تفاوت بررسی runtime با تضمین زمان کامپایل چیست؟
5. برای یک کار صف، چه زمانی انتقال payload به پردازشگر بهتر از قرض‌دادن آن است؟
