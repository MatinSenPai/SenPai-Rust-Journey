# ۰۲ — مالکیت و حافظه

بزرگترین تغییر ذهنی در مهاجرت از پایتون. اینجا نه زباله‌روبی (Garbage Collector) هست، نه `free()` دستی — به جاش کامپایلر تو همون زمان کامپایل، دقیقاً پیگیری می‌کنه که مسئولیت پاکسازی هر مقدار به عهده‌ی کیه، و اگه کدی بنویسی که این قضیه توش گنگ باشه اصلاً اونو برات نمی‌سازه (build نمی‌کنه). اینجا آروم پیش برو؛ این ماژول همون فونداسیونیه که بقیه‌ی چیزا (مثل borrowing، طول‌عمرها، اشاره‌گرهای هوشمند و حتی async) روش بنا می‌شن.
