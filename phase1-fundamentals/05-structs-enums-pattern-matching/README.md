# 05 — Structs, Enums & Pattern Matching

This is where Rust's type system starts actively working *for* you instead
of just enforcing rules. Structs group related data (like a Python
`@dataclass`); enums model "one of several distinct shapes" far more
precisely than Python typically does; `match` forces you to handle every
case. This trio is the foundation for how you'll model real backend domain
data in Phase 3-4 (and the anime-quote side-quest right after this module).
