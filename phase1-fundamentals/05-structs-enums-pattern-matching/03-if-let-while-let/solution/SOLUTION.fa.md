# راه‌حل

`if let` و `match` هر دو درست‌اند؛ انتخاب اینجا درباره‌ی خوانایی است. `if let` می‌گوید «اگر rating بود format کن، وگرنه default» و arm زائد ندارد.

`sum_stack` و `drain_positive` مالک `Vec<i32>` را می‌گیرند و چون `pop()` تغییر است parameter را `mut` می‌کنند. فراخوان پس از move دیگر بردار را ندارد. `for top in stack` نیز بردار را مصرف می‌کند، اما از ابتدا به انت‌ها می‌رود و درجا عضو‌ها را با `pop` حذف نمی‌کند؛ `while let` پشت‌به‌جلو و با تغییر واقعی پیش می‌رود.
