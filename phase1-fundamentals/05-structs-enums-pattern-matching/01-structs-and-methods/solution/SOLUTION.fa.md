# راه‌حل

در `impl Book`، `Self` دقیقاً همان `Book` است و با rename شدن نوع سالم می‌ماند. تبدیل `self.chapters_read as f64` cast عددی صریح Rust است؛ promotion ضمنی integer به float نداریم.

`describe` ابتدا `star` را به‌شکل `&str` می‌سازد و یک‌بار `format!` را اجرا می‌کند. اگر بی‌دلیل `&mut self` می‌گرفت، دسترسی انحصاری می‌خواست و امکان داشتن ارجاع‌های اشتراکی هم‌زمان را محدود می‌کرد. API باید کمترین سطح دسترسی لازم را بخواهد.
