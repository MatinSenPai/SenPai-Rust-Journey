# ۰۵.۱ — ساختارها و متدها (Structs and methods)

## تعریف یک ساختار (Struct)

```rust
struct Anime {
    title: String,
    episodes: u32,
    is_completed: bool,
}

let one_piece = Anime {
    title: String::from("One Piece"),
    episodes: 1100,
    is_completed: false,
};
```

یه struct در واقع فیلدهای نام‌گذاری شده و دارای نوع رو دور هم جمع می‌کنه — نزدیک‌ترین معادلش تو پایتون همون `@dataclass` هستش، با این تفاوت که اینجا نوعِ (type) تک‌تک فیلدها ثابت در نظر گرفته شده و همون موقع کامپایل بررسی می‌شه، و (همونطوری که تا الان دیگه می‌دونی) متغیر `one_piece` به صورت پیش‌فرض غیرقابل‌تغییر (immutable) هست مگه اینکه با `let mut` تعریفش کنی.

## متدها: بلاک‌های `impl`

```rust
impl Anime {
    // تابع مرتبط (بدون `self`) — به صورت (...)Anime::new فراخوانی می‌شه و نقش
    // کانستراکتور (constructor) رو بازی می‌کنه. سینتکس خاصی نداره و فقط یه توافقه.
    fn new(title: &str, episodes: u32) -> Self {
        Anime { title: title.to_string(), episodes, is_completed: false }
    }

    // متد (با `&self`) — شیءِ نمونه (instance) رو قرض می‌گیره و فقط اونو می‌خونه.
    fn describe(&self) -> String {
        format!("{} ({} episodes)", self.title, self.episodes)
    }

    // متد (با `&mut self`) — نمونه رو به شکل تغییرپذیر قرض می‌گیره و می‌تونه محتواش رو عوض کنه.
    fn mark_completed(&mut self) {
        self.is_completed = true;
    }
}

let mut op = Anime::new("One Piece", 1100);
println!("{}", op.describe());
op.mark_completed();
```

استفاده از `Self` (با S بزرگ) داخل یه بلاک `impl` یعنی «دقیقاً همین نوع فعلی» — این معادل همونه که دوباره بنویسی `Anime`، با این مزیت که اگه یه روزی اسم این نوع رو عوض کنی، این عبارت همچنان بدون دست‌خوردن درست کار می‌کنه. قسمتِ `title, episodes` تو اون حالتِ مختصرنویسی (shorthand) موقع مقداردهی به struct، در واقع "مختصرنویسی مقداردهی فیلد (field init shorthand)" نام داره: هر وقت اسم متغیرت دقیقاً با اسم فیلدت یکی باشه، می‌تونی از نوشتنِ `title: title` صرف‌نظر کنی و فقط همون اسم رو بنویسی.

قضیه‌ی استفاده از `&self` در مقابل `&mut self` در مقابل خودِ `self` (که مقدارش دارای مالکیته و کاملاً مصرف می‌شه) دقیقاً همون تمایز اشتراکی/تغییرپذیر/دارای مالکیت هست که تو ماژول قرض‌گرفتن دیدی، فقط با این تفاوت که اینجا روی «نمونه‌ای که متد روش صدا زده شده» اعمال می‌شه. از حالت خودِ `self` (توسط مقدار) تو فاز ۲ برای متدهای مصرف‌کننده‌ای که حالتِ زنجیره‌ای یا سازنده (builder-style) دارن استفاده می‌کنی.

## وظیفه‌ی تو

فایل `src/lib.rs` یه struct به اسم `Book` تعریف کرده (با حال و هوای این مخزن، قراره خوندنِ فصل‌های یه مانگا/کتاب رو پیگیری کنه). متدهاش رو پیاده‌سازی کن.
