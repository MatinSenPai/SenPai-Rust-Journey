# ۰۱.۱.۳ — شرط، حلقه و آشنایی اولیه با match

## دستور `if` یک عبارت (expression) است

```rust
let status = if score >= 90 { "A" } else if score >= 80 { "B" } else { "F" };
```

برای نوشتن شرط نیازی به پرانتز نیست، و برخلاف دستورات `if`/`else` تو پایتون، تا زمانی که همه‌ی شاخه‌ها (branches) یک نوع داده‌ی یکسان رو برگردونن، `if` تو Rust مستقیماً یه مقدار تولید می‌کنه. اینجا نیازی به operator سه‌گانه (ternary) نداری؛ این *همون* معادل سه‌گانه تو Rust هست.

## سه مدل حلقه (Loop)

- `loop { ... }` — تا زمانی که یه `break` صریح نباشه تا ابد می‌چرخه. چیز جالبش اینه که دستور `break value;` می‌تونه یه مقدار رو از دلِ حلقه بفرسته بیرون: مثلاً `let x = loop { break 5; };` مقدار `x` رو می‌کنه `5`.
- `while condition { ... }` — دقیقاً مثل پایتون کار می‌کنه.
- `for item in iterable { ... }` — روحش مثل همون `for` تو پایتونه، اما همیشه روی چیزی iterate می‌کنه که `IntoIterator` رو پیاده‌سازی کرده باشه (مثل محدوده‌ی `0..5`، آرایه‌ها، sliceها، و تو فاز ۲ می‌بینیم که برای `Vec`ها هم کار می‌کنه). تو Rust اصلاً مدل حلقه‌ی زبان C یعنی `for (i = 0; i < n; i++)` رو نداریم — به جاش از `for i in 0..n` استفاده می‌شه تا دقیقاً همون نتیجه رو بگیریم.

## دستور `match` — یه پیش‌نمایش

```rust
let description = match n {
    0 => "zero",
    1 | 2 => "one or two",
    3..=9 => "single digit, at least three",
    _ => "big",
};
```

دستور `match` در واقع روش Rust برای pattern-matching هستش — بیشتر شبیه یه `switch` فوق‌پیشرفته‌ست تا اینکه بخواد شبیه نسخه‌ی پایتونیش باشه، و از طرفی **جامع (exhaustive)** هست: کامپایلر تا زمانی که برای تمام حالت‌های ممکن فکری نکرده باشی اصلاً کدت رو بیلد (build) نمی‌کنه (اون `_` بالا در واقع حالتِ «هر چیز دیگه»، یعنی همون کار `case _:` تو پایتونه). تو این درس فقط روی همون اعداد صحیح معمولی ازش استفاده می‌کنیم؛ اما تو ماژول structها و enumها (تو فاز یک) اونجاست که `match` تازه خودنمایی می‌کنه و ارزش واقعیش رو نشون میده.
