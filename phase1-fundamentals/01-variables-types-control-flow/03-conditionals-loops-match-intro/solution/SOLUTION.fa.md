# راه‌حل

`letter_grade` یک expression کامل `if` است. string literal داخل فایل اجرایی قرار دارد و ارجاع آن `'static` است؛ یعنی برای کل اجرای برنامه معتبر می‌ماند.

`first_multiple_above` از `loop` استفاده می‌کند چون `break candidate` مقدار loop را برمی‌گرداند. نسخه‌ی `while` به اتصال تغییرپذیر بیرونی نیاز دارد.

`match` باید برای هر `i32` مقدار بسازد. حذف `_` باعث پیام تشخیصی مربوط به `non-exhaustive patterns` می‌شود؛ کامپایلر نمی‌تواند ورودی‌های دیگر را بدون arm ر‌ها کند.
