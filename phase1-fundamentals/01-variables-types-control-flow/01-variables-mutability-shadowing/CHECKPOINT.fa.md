# چک‌پوینت

1. اگه `mut` رو از شمارنده‌ی تابع `increment_n_times` پاک کنی ولی بازم سعی کنی مقدارش رو تغییر بدی چه خطای کامپایلی می‌گیری؟ خط اصلی خطا رو اینجا پیست کن.
2. با سایه‌زنی (shadowing) می‌تونی نوعِ یه متغیر رو عوض کنی؛ اما با `mut` نمی‌تونی. سعی کن `parse_and_double` رو طوری تغییر بدی که به جای سایه‌زنی از `mut input` استفاده کنه ولی همون منطق رو داشته باشه — چه خطای کامپایلی ظاهر می‌شه و چرا؟
3. با کلمات خودت بگو: تو یه کد واقعی کِی سراغ `mut` می‌ری و کِی سراغ سایه‌زنی؟
4. تفاوت `const` با یه `let` که بالای تابع `main` تعریف شده چیه (به جز توافقی که برای استفاده از حروف بزرگ برای اسمش هست)؟
