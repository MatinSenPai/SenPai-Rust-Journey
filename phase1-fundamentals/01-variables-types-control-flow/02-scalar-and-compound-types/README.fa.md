# ۰۱.۱.۲ — نوع‌های scalar و compound

زبان Rust از نوع **statically typed** استفاده می‌کنه: نوع هر مقدار تو زمان کامپایل کاملاً مشخصه (معمولاً خودش استنتاج (infer) می‌شه، بعضی وقتا هم باید خودت صریح بنویسیش)، و هیچ‌وقت هم عوض نمی‌شه. اون چیزی که تو پایتون داریم که می‌نویسی `x = 5; x = "hi"` اصلاً تو Rust برای همون یه متغیر شدنی نیست (سایه‌زنی یا shadowing فقط بهت اجازه می‌ده که *همون اسم رو* برای یه نوع جدید استفاده کنی — همونطور که تو درس قبل دیدیم، نوعِ اون متغیرِ زیرین همچنان ثابت می‌مونه).

## نوع‌های پایه (Scalars) — یک مقدار تکی

| نوع | چیه | توضیحات |
|---|---|---|
| `i8`..`i128`, `isize` | اعداد صحیح علامت‌دار (signed) | اگه چیزی نگی، پیش‌فرض `i32` هست |
| `u8`..`u128`, `usize` | اعداد صحیح بدون علامت (unsigned) | از `usize` برای ایندکس‌ها یا اندازه‌ها استفاده می‌شه — سایزش دقیقاً اندازه‌ی عرضِ پوینترِ سیستمته |
| `f32`, `f64` | اعداد اعشاری (floats) | پیش‌فرض `f64` هست |
| `bool` | `true`/`false` | دقیقاً مثل پایتون |
| `char` | یک کاراکتر یونیکد (Unicode scalar) | **همیشه ۴ بایت** — با یه بایت فرق داره، با یه حرف ساده‌ی الفبا هم یکی نیست (مثلاً `'🦀'` یه `char` حساب می‌شه) |

اعداد صحیح تو Rust سایز ثابتی دارن و تو بیلدِ دیباگ (debug build) **اگه سرریز (overflow) بشن کرش (panic) می‌کنن** (مثلاً سقف `u8` مقدار ۲۵۵ هستش؛ برخلاف پایتون که نوع `int` هر سایزی رو بدون مشکل هندل می‌کنه، اینجا `255u8 + 1` به جای اینکه بی‌سروصدا بچرخه و صفر بشه یا سایزش بزرگتر شه، کرش می‌کنه). این یه تفاوت واقعی و عمدی با اون مدلِ پایتونه که «اعداد تو هر سایزی کار می‌کنن» — تو Rust اینکه نوع عدد صحیح رو با سایز درستی انتخاب کنی یه تصمیم طراحیِ واقعیه.

## نوع‌های ترکیبی (Compounds) — مجموعه‌ای از مقادیر

- **توپل‌ها (Tuples)** — سایزشون ثابته، و می‌تونن از انواع مختلف ترکیب بشن: `let point: (f64, f64) = (1.0, 2.0);` برای دسترسی هم از `0.`، `1.` استفاده می‌شه.
- **آرایه‌ها (Arrays)** — سایزشون ثابته، همه‌ی عناصرشون فقط از یک نوع باید باشن و طولِ آرایه خودش بخشی از نوع (type) اون محسوب می‌شه: `let nums: [i32; 3] = [1, 2, 3];` — یعنی `[i32; 3]` و `[i32; 4]` واقعاً دو تا نوعِ (type) کاملاً متفاوتن. اگه یه مجموعه‌ی تک‌نوع و با سایز قابل افزایش می‌خوای، باید بری سراغ `Vec<T>` (که تو فاز ۲ می‌بینیمش).
