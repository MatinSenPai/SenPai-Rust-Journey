# راه‌حل

```rust
pub fn count_vowels(s: &str) -> usize {
    s.chars().filter(|c| "aeiouAEIOU".contains(*c)).count()
}
```
یه قرضِ اشتراکی (`&str`) تمام اون چیزیه که این تابع بهش نیاز داره — چون فقط می‌خواد بخونه. متد `.chars()` یه iterator از `char`ها می‌ده (تو فاز ۲ بحث iteratorها کاملاً رسمی و جدی می‌شه؛ این فقط یه پیش‌نمایش دیگه‌ست)، متد `.filter` فقط حروف صدادار رو نگه می‌داره و `.count()` هم اون‌ها رو می‌شمره. برخلاف تمرین `(total_length(strings: Vec<String` مربوط به دو درس قبل که از قصد مالکیت رو از فراخواننده می‌گرفت، تو این تمرین متغیر `text` بعد از اجرای تابع برای فراخواننده‌اش کاملاً معتبر و قابل استفاده باقی می‌مونه.

```rust
pub fn append_exclamation(s: &mut String) {
    s.push_str("!");
}
```
متغیر `&mut String` یه دسترسیِ موقت، انحصاری و با قابلیت نوشتن رو بهت می‌ده. اینجا نیازی به هیچ خروجیِ برگشتی نیست — همون `String`ی که فراخواننده داشت، به‌طور مستقیم از طریق همین ارجاع تغییر کرد.

```rust
pub fn swap_and_report(a: &mut i32, b: &mut i32) -> String {
    let (orig_a, orig_b) = (*a, *b);
    std::mem::swap(a, b);
    format!("swapped {orig_a} and {orig_b}")
}
```
تو این کد `a*` و `b*` از طریق یه فرآیند به اسم **نشان‌زدایی (dereference)**، میان اون مقادیر `i32`ای رو که ارجاع دارن بهشون اشاره می‌کنن، از زیرشون می‌خونن (و چون `i32` خودش قابلیت `Copy` رو داره، دستور `(a, *b*)` دو تا کپی مستقل ازشون می‌سازه — که با این کار، هیچ تداخلی با سیستم borrow-checker به وجود نمیاد). متد `std::mem::swap` دو تا پارامتر از جنس `&mut T` می‌گیره و مقادیری که بهشون اشاره می‌کنن رو با هم جابه‌جا می‌کنه — این کار همزمان کاملاً مجازه، چرا که `a` و `b` دارن دو تا `i32` *مختلف و جدا از هم* رو قرض می‌گیرن. اون قانونِ «در هر زمان فقط یک `&mut`» برای هر یک **مقدار واحد** صدق می‌کنه، نه اینکه یه محدودیت کلی رو تعدادِ کل ارجاع‌های `&mut` موجود در سرتاسر یک برنامه باشه.
