# ۰۶.۲ — نوع `Result` و عملگر `?`

## نوع `Option` برای عدم وجود مقدار، نوع `Result` برای شکست با دلیل مشخص

```rust
enum Result<T, E> {
    Ok(T),
    Err(E),
}
```

جایی که `<Option<T` می‌گه «ممکنه اینجا هیچی نباشه»، `<Result<T, E` می‌گه «ممکنه این کار با شکست مواجه بشه، و اینم دلیلشه (*why*).» از قبل به صورت غیرمستقیم ازش استفاده کردی: دستور `()42".parse::<i32"` یه `<Result<i32, ParseIntError` برمی‌گردونه، نه فقط یه `<Option<i32`، چون وقتی پارس کردن شکست می‌خوره، اینکه بدونی «رشته‌ی ورودی عدد معتبری نبود» برای فراخواننده‌ی تابع (caller) خیلی مفیدتر از یه `None` خالیه.

```rust
fn divide(a: f64, b: f64) -> Result<f64, String> {
    if b == 0.0 {
        Err("cannot divide by zero".to_string())
    } else {
        Ok(a / b)
    }
}
```

## هندل کردن یه `Result`

```rust
match divide(10.0, 2.0) {
    Ok(value) => println!("Result: {value}"),
    Err(e) => println!("Error: {e}"),
}

divide(10.0, 0.0).unwrap();          // برنامه رو با پیغامِ داخلِ Err کرش (panic) می‌کنه
divide(10.0, 0.0).unwrap_or(0.0);    // عدد 0.0 می‌ده، خبری از panic نیست
```

## عملگر `?` — خطاها رو پاس بده بالا، بدون اینکه تو هر قدم یه `match` بنویسی

```rust
fn compute(a: f64, b: f64, c: f64) -> Result<f64, String> {
    let step1 = divide(a, b)?;     // اگه تابع divide مقدار Err برگردونه، همین تابعی 
    let step2 = divide(step1, c)?; // که الان توشیم هم همون Err رو بلافاصله برمی‌گردونه
    Ok(step2)
}
```

عبارت `?expr` یه خلاصه‌نویسی برای این حرفه: «اگه این مقدار `(Ok(value` هست، متغیر `value` رو از توش دربیار و ادامه بده؛ اما اگه `(Err(e` هست، همین الان از *همین تابعی که توش هستم* مقدار `(Err(e` رو برگردون.» این همون چیزیه که هندل کردنِ خطاها تو Rust رو جذاب و خوش‌دست می‌کنه، به جای اینکه مجبورت کنه تو هر فراخوانی که ممکنه خطا بده، یه هرم از `match`ها بسازی — از فاز ۳ به بعد که تقریباً تمام عملیات‌های دیتابیس و هندلرهای HTTP یه `Result` برمی‌گردونن، قراره دائماً از `?` استفاده کنی. نکته‌اش اینه: عملگر `?` فقط می‌تونه داخل تابعی استفاده بشه که خروجیِ خود اون تابع هم از نوع `Result` (یا `Option`) باشه، اون هم با یه نوعِ خطای سازگار — اگه سعی کنی ازش داخل `()fn main` استفاده کنی بدون اینکه نوعِ بازگشتیِ `main` رو دستکاری کنی، همون لحظه یه خطای کامپایل می‌گیری (تو سؤالات چک‌پوینت امتحانش کن).
