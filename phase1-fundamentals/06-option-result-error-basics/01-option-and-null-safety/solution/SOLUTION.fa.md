# راه‌حل

```rust
pub fn find_by_id(users: &[(u32, String)], id: u32) -> Option<String> {
    users.iter().find(|(uid, _)| *uid == id).map(|(_, name)| name.clone())
}
```
متد `()find.` (که یه متد مال iteratorهاست — فاز ۲ اونا رو دقیق بررسی می‌کنه) یه خروجی از نوعِ `<((Option<&(u32, String` برمی‌گردونه؛ متد `()map.` میاد *داخل* همون `Option` محتوا رو تغییر می‌ده، بدون اینکه لازم باشه اول بازش کنی (`unwrap` کنی) — و اگه `()find.` همون اولِ کار جواب `None` برگردونه، متدِ `()map.` کلاً نادیده گرفته می‌شه و کلِ اون عبارت مساوی `None` می‌مونه. اینکه خروجی رو به جای `<Option<&String` به شکلِ `<Option<String` (یعنی یه کپی مستقل و دارای مالکیت (owned)) برگردوندیم، باعث می‌شه اعتبار خروجی از اسارت و گره خوردن به قرضِ متغیر `users` خلاص بشه — اینطوری، فراخواننده‌ی تابع (caller) می‌تونه اسمِ پیدا شده رو کاملاً مستقل برای خودش نگه داره؛ این قضیه وقتی این مدل پیدا کردنِ اطلاعات به یه مرزِ واقعی‌تر از توابع برسه (مثل یه هَندلِر (handler) برای یه API تو فاز ۳)، جاهایی که دیگه لیستِ اصلیِ `users` ممکنه از قبل پاک شده باشه، به‌شدت مهم می‌شه.

```rust
pub fn average_known_age(ages: &[Option<u32>]) -> Option<f64> {
    let known: Vec<u32> = ages.iter().filter_map(|a| *a).collect();
    if known.is_empty() {
        return None;
    }
    let sum: u32 = known.iter().sum();
    Some(sum as f64 / known.len() as f64)
}
```
متد `()filter_map.` در واقع عملِ فیلتر کردن و `map` کردن رو به طور یکجا انجام می‌ده: کافیه بهش یه closure بدی که خروجیِ `<Option<U` برگردونه، اون وقت اون خودش فقط مقادیرِ `Some` رو که از قبل هم باز (unwrapped) شدن نگه می‌داره — این دقیقاً معادل همینه که بگی «تمامِ `None`ها رو نادیده بگیر، و بقیه رو نگه دار.» برگردوندن مقدارِ `None` برای یه ورودی که کلاً خالیه (empty)، فقط یه کار روتینِ تدافعی برای جلوگیری از باگ نیست؛ بلکه این تنها جوابِ درسته که از لحاظِ typeها هم معنی داره — تو دنیای ریاضیات هیچ مقدارِ `f64` معناداری که بهت بگه «میانگینِ صفر عدد چنده»، وجود نداره؛ در نتیجه، `<Option<f64` از طریق سیستم نوع (type system) به فراخواننده‌ی تابع اجبار می‌کنه که باید دقیقاً همون حالتِ ناموجود رو هم هندل کنه، و این، همون تضمینیه که کل این درس به خاطرش نوشته شده.
