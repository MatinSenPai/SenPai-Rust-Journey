# ۰۶.۱ — نوع `Option` و ایمنی null

## تو زبان Rust چیزی به اسم `null` نداریم

پایتون (و خیلی از زبان‌های دیگه) این اجازه رو می‌دن که هر متغیری به طور غیرمنتظره‌ای `None`/`null` بشه — مثلاً تابعی که تو نوعِ خروجیش نوشته قراره یه `User` برگردونه، همچنان می‌تونه بهت یه `None` تحویل بده، و هیچ چیزی هم مجبورت نمی‌کنه که قبل از استفاده کردن چکش کنی. این داستان اونقدر منبع رایجی واسه باگ‌هاست که حتی خود مخترعِ این قضیه یعنی Tony Hoare، ارجاع null رو «اشتباه میلیارد دلاریِ» خودش نامیده.

جواب Rust به این مشکل: **اصلاً چیزی به اسم null نداریم**. متغیری که نوعش `User` هست *همیشه* یه `User` واقعیه. اگه یه جایی ممکنه مقداری غایب باشه، این موضوع همونجا تو خودِ نوع (type) متغیر گنجونده می‌شه:

```rust
enum Option<T> {
    Some(T),
    None,
}
```

نوعِ `<Option<T` فقط یه enum معمولیه دقیقاً هم‌جنس همون چیزی که تو ماژول قبلی دیدیم (در واقع این نوع با استفاده از همون ابزارهایی که تا الان یاد گرفتی، تو کتابخونه‌ی استاندارد زبان یا همون stdlib تعریف شده). وقتی می‌بینی `find_user(id) -> Option<User>`، این داره مستقیماً از طریق همون امضای نوعِ خروجی (type signature) بهت می‌گه «ممکنه این تابع هیچ چیزی پیدا نکنه» — و از اونجایی که یه `<Option<User` مساوی با یه `User` نیست، کامپایلر بهت اجازه نمی‌ده که مستقیماً `.name()` رو روش صدا بزنی. تو **مجبوری** اون حالت `None` رو یه جایی تو زمان کامپایل (compile time) هندل کنی، تا تازه بعدش بتونی به اون `User`ی که درونشه دسترسی پیدا کنی.

## روش‌های اصلیِ کار با `<Option<T`

```rust
let maybe_age: Option<u32> = Some(25);

maybe_age.is_some();                    // از نوعِ bool: مقدارش می‌شه true
maybe_age.is_none();                    // از نوعِ bool: مقدارش می‌شه false
maybe_age.unwrap();                     // عدد 25، یا کرشِ برنامه (PANIC) در صورتی که None باشه — تو درس بعدی می‌بینیمش
maybe_age.unwrap_or(0);                 // عدد 25، یا اگه None باشه همون 0
maybe_age.unwrap_or_default();          // عدد 25، یا اگه None باشه پیش‌فرضِ خودِ نوع (واسه u32 همون 0 می‌شه)
maybe_age.map(|age| age + 1);           // مقدارِ (Some(26 — مقداری که درونشه رو تغییر می‌ده (البته اگه وجود داشته باشه)
if let Some(age) = maybe_age { /* ... */ }   // اینم که مال درس قبلیه
```

بد نیست روی `.map()` یه کم مکث کنی: این متد بهت اجازه می‌ده که مقدار رو *داخل* یه `Option` تغییر شکل (transform) بدی، بدون اینکه نیاز باشه دستی بیاریش بیرون و دوباره بذاریش تو بسته — اگه `None` باشه همون `None` می‌مونه، اگه `Some(x)` باشه تبدیل می‌شه به `Some(f(x))`. این دقیقاً همون ساختاریه که قراره بعداً روی `Result` (تو درس بعدی) و روی iteratorها (تو فاز ۲) به وفور ببینیش.

## وظیفه‌ی تو

توابع رو تو فایل `src/lib.rs` پیاده‌سازی کن — اینجا قراره یه سیستم خیلی کوچیک واسه «پیدا کردن یه کاربر با id» با تکیه‌ی کامل به `Option` بسازی، و قرار نیست هیچ‌جا تو کدت `panic` داشته باشی.
