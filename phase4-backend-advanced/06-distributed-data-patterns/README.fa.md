# ماژول ۶ — الگوهایِ دادهِ توزیع‌شده

تراکنش در مرزِ یک دیتابیس تمام می‌شود. این ماژول می‌گوید وقتی یک عملیاتِ کسب‌وکاری چند دیتابیس را دربرمی‌گیرد چه می‌کنی: ساگا با گام‌هایِ جبرانی، event sourcing و CQRS (با روایتی صادقانه از اینکه کِی نباید به‌کارشان بست)، و مدل‌هایِ چندمستاجری که تعیین می‌کنند یک استقرار چطور امن به چند مشتری سرویس بدهد.

۱. [0۱ — ساگا و تراکنش‌هایِ جبرانی](01-sagas-and-compensating-transactions/README.fa.md)
   — یک عملیاتِ چندگامی میانِ سرویس‌ها، و راهِ برگرداندنش.
۲. [0۲ — Event sourcing و CQRS](02-event-sourcing-and-cqrs/README.fa.md)
   — مروری سبک و صادقانه، از جمله اینکه کِی نباید به‌کارشان بست.
۳. [0۳ — مدل‌هایِ چندمستاجری (multi-tenancy)](03-multi-tenancy-models/README.fa.md)
   — اسکیمایِ مشترک، اسکیما به‌ازایِ هر مستاجر، دیتابیس به‌ازایِ هر مستاجر، و مصالحه‌هایشان.
