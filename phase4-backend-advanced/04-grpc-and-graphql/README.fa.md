# ۰۴ — قراردادهای gRPC و GraphQL

فاز ۳ با استفاده از axum بهمون ساختن REST APIها رو یاد داد — که یعنی انتقال JSON روی بستر HTTP، و برای هر نوع منبع و داده‌ای، یه نقطه پایانیِ (endpoint) مستقل. این ماژول دو تا جایگزین دیگه رو پوشش میده که تو کار بک‌اند حتماً باهاشون برخورد می‌کنی: **gRPC** (یه پروتکل RPC که پیام‌ها رو به شکل باینری و به شدت نوع-بندی‌شده (strongly-typed) و بر پایه‌ی HTTP/2 و Protocol Buffers جابجا می‌کنه، و واسه ارتباط سرویس به سرویس به شدت محبوبه) و **GraphQL** (یه زبان کوئری که به کلاینت‌ها اجازه میده تو یه گرافِ تودرتو از انواع (types)، فقط و فقط همون فیلدهایی که دقیقاً بهشون نیاز دارن رو درخواست بدن، و واسه APIهایی که کلاینت‌محور (client-facing) هستن و مصرف‌کننده‌های متنوعی دارن به شدت پرکاربرده). هیچ‌کدوم از این دو تا قرار نیست به طور کامل جای REST رو بگیرن — هر کدومشون واسه شرایط خاص و مشخصی بهترین انتخابن، که تو هر درس راجع‌به همون شرایط بحث می‌شه.
