# Module 6 — System design fundamentals

Every other module in this repo builds something. This one names things
you've *already built* with vocabulary that shows up in interviews, RFC
documents, and incident postmortems — CAP theorem, scaling, load
balancing, idempotency, distributed locking. None of these are new ideas
by the time you reach this module; the goal is connecting each term to a
concrete decision you already made somewhere in this repo.
