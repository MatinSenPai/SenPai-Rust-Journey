# ماژول ۶ — مبانی طراحی سیستم (System design fundamentals)

تک‌تک ماژول‌های دیگه‌ای که تو این مخزن (repo) دیدی، داشتن یه چیزی رو با کد می‌ساختن. اما این ماژول کارش اینه که روی همون چیزهایی که تا حالا *خودت ساختی*، اسم‌ها و اصطلاحاتی رو بذاره که معمولاً تو مصاحبه‌های استخدامی، داکیومنت‌های RFC، و گزارش‌های کالبدشکافیِ حوادث سیستم (incident postmortems) زیاد باهاشون برخورد می‌کنی — مفاهیمی مثل قضیه CAP، مقیاس‌پذیری (scaling)، متعادل‌کننده‌ی بار (load balancing)، اصل بی‌اثر بودن تکرار (idempotency)، و قفل‌های توزیع‌شده (distributed locking). تا اینجای کار که رسیدی، هیچ کدوم از این مفاهیم اصلاً ایده‌های جدیدی برات نیستن؛ هدف این درس فقط اینه که تک‌تک این کلمات و اصطلاحات رو دقیقاً گره بزنه به یه تصمیمِ مشخص و ملموسی (concrete decision) که خودت از قبل یه جایی تو همین مخزن گرفتی و پیاده‌اش کردی.
