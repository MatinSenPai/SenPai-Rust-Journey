# ماژول ۲ — محدودسازیِ نرخ و فشارِ برگشتی

سرویسی که همه‌چیز را بپذیرد برایِ همه از کار می‌افتد. این ماژول الگوریتم‌هایی را پوشش می‌دهد که تصمیم می‌گیرند چه کسی وارد شود، اینکه یک حد را چطور روی چند نمونه اعمال کنی، و اینکه سیستمِ پُر چه باید بکند: فشار را برگرداند، بار را حذف کند، یا بگذارد صف تا لحظه‌یِ درد بزرگ شود.

۲. [0۲ — محدودسازیِ نرخِ توزیع‌شده با Redis و Lua](02-distributed-rate-limiting-redis-lua/README.fa.md)
   — یک حدِ مشترک میانِ چند نمونه، که با یک اسکریپتِ Lua اتمی می‌شود.
