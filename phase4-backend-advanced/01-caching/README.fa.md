# ماژول ۱ — کش (Caching)

ارزان‌ترین درخواست آن است که اصلاً فرستاده نشود. این ماژول کش را از یک فراخوانیِ ساده‌یِ Redis تا مسئله‌هایِ طراحیِ دورِ آن می‌برد: کدام راهبرد به کدام داده می‌خورد، کش چطور کهنه می‌شود، وقتی یک کلیدِ پرتراکنش زیرِ بار منقضی شود چه می‌شود، و چرا یک کشِ درون‌پردازه‌ای جلویِ Redis اغلب اولین حرکتِ درست است.

۱. [0۱ — Redis از Rust](01-redis-from-rust/README.fa.md)
   — کریتِ redis، مدیریتِ اتصال، و همان چند فرمانی که یک کش واقعاً استفاده می‌کند.
۲. [0۲ — راهبردهایِ کش و باطل‌سازی](02-cache-aside-ttl-invalidation/README.fa.md)
   — cache-aside، write-through، TTL و مسئله‌یِ باطل‌سازی.
۳. [0۳ — محافظت در برابرِ stampede، single-flight و jitterِ TTL](03-stampede-protection-and-single-flight/README.fa.md)
   — وقتی یک کلیدِ پرتراکنش زیرِ بار منقضی می‌شود چه می‌شود، و سه راهِ جلوگیری.
۴. [0۴ — کشِ درون‌پردازه‌ای (moka) و الگویِ دولایه](04-in-process-caching-and-two-tier/README.fa.md)
   — کشی داخلِ خودِ پردازه جلویِ Redis، و بهایِ سازگاریِ داشتنِ دو کش.
