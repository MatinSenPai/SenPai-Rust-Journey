# ماژول ۵ — مشاهده‌پذیری (Observability)

چیزی را که نمی‌بینی نمی‌توانی درست کنی. لاگِ ساخت‌یافته، متریک و ردیابیِ توزیع‌شده سه راهی‌اند که یک سیستمِ در حالِ اجرا خودش را توضیح می‌دهد؛ این ماژول هرکدام را پوشش می‌دهد و با بخشی تمام می‌شود که آموزش‌ها از آن می‌گذرند: تبدیلشان به SLO و آلارمی که یک آدم بتواند با آن زندگی کند.

۱. [0۱ — لاگِ ساخت‌یافته با tracing](01-structured-logging-with-tracing/README.fa.md)
   — span، event و فیلد به‌جایِ رشته‌یِ لاگ.
۲. [0۲ — متریک‌ها (RED و USE) و Prometheus](02-metrics-and-prometheus/README.fa.md)
   — counter، gauge، histogram، و اینکه کدام عددها را باید دید.
۳. [0۳ — ردیابیِ توزیع‌شده با OpenTelemetry، سرتاسری](03-distributed-tracing-with-opentelemetry/README.fa.md)
   — یک trace از میانِ چند سرویس، از instrumentation تا backend.
۴. [0۴ — SLO، آلارم و واقعیتِ on-call](04-slos-alerting-and-on-call/README.fa.md)
   — error budget، آلارم‌هایی که ارزشِ بیدار شدن دارند، و آن‌هایی که ندارند.
