# Module 5 — Observability

You cannot fix what you cannot see. Structured logs, metrics, and distributed traces are the three ways a running system explains itself; this module covers each, and ends with the part tutorials skip: turning them into service-level objectives and alerts a human can live with.

1. [01 — Structured logging with tracing](01-structured-logging-with-tracing/README.md)
   — Spans, events and fields instead of log strings.
2. [02 — Metrics (RED and USE) and Prometheus](02-metrics-and-prometheus/README.md)
   — Counters, gauges, histograms, and which numbers to watch.
3. [03 — Distributed tracing with OpenTelemetry, end to end](03-distributed-tracing-with-opentelemetry/README.md)
   — One trace across several services, from instrumentation to a backend.
4. [04 — SLOs, alerting and on-call reality](04-slos-alerting-and-on-call/README.md)
   — Error budgets, alerts worth waking up for, and the ones that are not.
