# واژه‌نامه‌ی یکدست SenPai

این واژه‌نامه مرجع ثابت درس‌هاست. در نخستین کاربرد هر اصطلاح، فارسی و انگلیسی را کنار هم می‌آوریم و بعد از معادل فارسی استفاده می‌کنیم.

| اصطلاح انگلیسی | فارسی معیار | توضیح کوتاه |
|---|---|---|
| Ownership | مالکیت | مسئولیت یکتای آزادسازی یک مقدار |
| Move | انتقال | واگذاری مالکیت از یک نام یا محدوده به دیگری |
| Borrowing | قرض‌گیری | دسترسی موقت از راه ارجاع بدون گرفتن مالکیت |
| Shared reference | ارجاع اشتراکی | دسترسی فقط‌خواندنی با `&T` |
| Mutable reference | ارجاع تغییرپذیر | مجوز انحصاری و موقت ویرایش با `&mut T` |
| Lifetime | طول عمر | بازه‌ای که یک ارجاع معتبر است |
| Lifetime elision | حذفِ طول‌عمر | قواعدی که طول‌عمرِ یک ارجاع را بدونِ نوشتنِ صریحِ `'a` استنتاج می‌کنند؛ رویِ متدها خروجیِ حذف‌شده طول‌عمرِ `self` را می‌گیرد، ولی فیلدهایِ ساختار را هیچ قاعده‌ای پوشش نمی‌دهد |
| Trait | صفت (Trait) | قراردادی برای رفتار مشترک میان نوع‌ها |
| Required method | متدِ اجباری | متدی در یک صفت بدونِ بدنه، فقط یک امضا؛ هر پیاده‌کننده باید نسخه‌ی خودش را بنویسد |
| Default method | متدِ پیش‌فرض | متدی در یک صفت با بدنه؛ هر پیاده‌کننده رایگان می‌گیردش، مگر خودش بازنویسی‌اش کند |
| Generic | جنریک | کدی که یک‌بار نوشته می‌شود و رویِ یک نوع پارامتری‌شده؛ کامپایلر آن را برایِ هر نوعِ ملموسِ واقعاً استفاده‌شده جداگانه کامپایل می‌کند (تک‌ریختی‌سازی)، نه اینکه مثلِ تایپِ اردکیِ پایتون سرِ اجرا حل شود |
| Trait bound | کران | محدودیتی رویِ یک پارامترِ جنریک، `T: SomeTrait`؛ می‌گوید یک نوعِ جایگزین دقیقاً چه کاری از دستش برمی‌آید. درون‌خطی (`<T: Trait>`) یا، وقتی چندتا جمع شوند، بعدِ امضا با `where` |
| Monomorphization | تک‌ریختی‌سازی | تولیدِ یک نسخه‌ی کاملاً جداگانه و ملموس از یک تابع/نوعِ جنریک، به‌ازایِ هر نوعِ واقعاً استفاده‌شده، سرِ کامپایل؛ دلیلِ رایگان‌بودنِ جنریک‌ها در زمانِ اجرا |
| Associated type | نوعِ وابسته | نوعِ جانشینی که یک صفت اعلام می‌کند و هر پیاده‌سازی دقیقاً یک‌بار پرش می‌کند |
| Generic trait parameter | پارامترِ جنریکِ صفت | پارامتری که رویِ خودِ صفت نوشته می‌شود، `trait Converts<T>`، نه رویِ تابع یا ساختار؛ برخلافِ نوعِ وابسته، یک نوع می‌تواند این صفت را چند بار پیاده کند — یک‌بار برایِ هر Tِ مشخص، به قیمتِ اینکه نقطه‌ی صدا زدن گاهی باید بگوید کدام impl را می‌خواهد |
| TryFrom / TryInto | تبدیلِ خطاپذیر | خواهرِ خطاپذیرِ From/Into؛ `try_from` به‌جایِ `U` یک `Result<U, Self::Error>` می‌دهد، و پیاده‌سازیِ آن رایگان `TryInto` را هم می‌دهد |
| Widening | پهن‌شوندگی | تبدیلِ عددی به نوعی با جایِ بیشتر؛ هرگز شکست نمی‌خورد، همیشه یک `From` |
| Narrowing | کوچک‌شوندگیِ عددی | تبدیلِ عددی به نوعی با جایِ کمتر؛ ممکن است جا نشود، همیشه یک `TryFrom` |
| Supertrait | ابرصفت | صفتی که صفتِ دیگری آن را پیش‌نیاز اعلام می‌کند، `trait B: A`؛ وابستگیِ سطحِ صفت، نه ارث‌بری — هیچ‌چیزی از `A` رایگان منتقل نمی‌شود، هر دو `impl` را جدا می‌نویسی |
| Blanket impl | پیاده‌سازیِ فراگیر | یک `impl` که یک‌بار برایِ هر نوعی که یک کراند را دارد نوشته می‌شود، `impl<T: Bound> Trait for T`، نه فقط یک نوعِ ملموس |
| Orphan rule | قاعده‌ی یتیم | فقط اگر صفت یا نوع در crateِ خودت تعریف شده باشد می‌شود آن صفت را برایِ آن نوع پیاده‌سازی کرد؛ جلویِ تصادمِ دو crateِ بی‌ربط را می‌گیرد |
| Future | کار آینده (Future) | محاسبه‌ای که شاید هنوز کامل نشده باشد |
| Runtime | محیط اجرا (Runtime) | سامانه‌ای که کارهای async را زمان‌بندی و اجرا می‌کند |
| async / await | async / await | کلیدواژه‌هایی که تابعی را ناهمگام می‌کنند؛ `async fn` یک `Future` برمی‌گرداند و `.await` منتظرِ آماده‌شدنِ آن `Future` می‌ماند تا مقدارش را بیرون بکشد |
| Poll<T> | Poll<T> | شمارشیِ خروجیِ `poll`: `Ready(T)` (مقدار آماده است) یا `Pending` (هنوز نه — بعداً دوباره امتحان کن) |
| Pin<P> | Pin<P> | قولی که مقدارِ پشتِ یک اشاره‌گر، بعد از پین‌شدن، دیگر هرگز جابه‌جا نمی‌شود؛ چون بدنه‌ی یک `async fn` به یک ماشینِ وضعیت تبدیل می‌شود که ممکن است بینِ نقاطِ تعلیقش به خودش ارجاع بدهد، `Future::poll` با گرفتنِ `Pin<&mut Self>` دقیقاً همین را تضمین می‌کند |
| Waker | Waker | دستگیره‌ای که یک `Future`ِ `Pending` نگه می‌دارد و وقتی دوباره ارزشِ `poll` شدن پیدا کرد رویش `wake` را صدا می‌زند، تا اجراکننده به‌جایِ حلقه‌زدنِ مدام، منتظر بماند |
| Task | تسک (Task) | واحدِ مستقلِ کاری که `tokio::spawn` به یک محیط اجرا می‌سپارد؛ یک `Future`ِ مالک‌شده که به‌طور همیاری‌طور، کنارِ هر تسکِ دیگر، رویِ یک استخرِ کوچک از ریسمان‌هایِ واقعیِ سیستم‌عامل (یا فقط یکی، زیرِ حالتِ `current_thread`) زمان‌بندی می‌شود — به‌مراتب ارزان‌تر از ساختنِ یک ریسمانِ OS، و دقیقاً همین چیزی است که spawn کردنِ هزاران‌تایش را عادی می‌کند |
| Stream | استریم (Stream) | نسخه‌ی async صفتِ Iterator: `poll_next(self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll<Option<Self::Item>>` به‌جایِ `next(&mut self) -> Option<Self::Item>`؛ مقدارها را یکی‌یکی، به‌طورِ async، تا `None` می‌دهد. از کریتِ `futures_core` می‌آید، دوباره از راهِ `tokio_stream` صادر شده؛ با `StreamExt::next()` در یک حلقه‌ی `while let` رانده می‌شود، چون Rust معادلِ `async for` ندارد |
| async fn in traits (AFIT) | صفتِ async (AFIT) | نوشتنِ `async fn` مستقیم داخلِ یک صفت، بدونِ هیچ ماکرویی، پایدار از Rust 1.75؛ یک تابعِ جنریکِ کراندار به همان صفت می‌تواند صدایش بزند، ولی نمی‌شود پشتِ `dyn Trait` گذاشتش — کامپایلر نمی‌تواند برایِ یک `async fn` جایِ ثابتی تویِ vtable باز کند |
| #[async_trait] | ماکروی `#[async_trait]` | ماکرویی از کریتِ `async-trait` که هر `async fn` را داخلِ یک صفت (و پیاده‌سازی‌هایش) به متدی معمولی با خروجیِ `Pin<Box<dyn Future<...> + Send>>` بازمی‌نویسد؛ این بازنویسی ایمنیِ شیء را برمی‌گرداند — `Box<dyn Trait>` دوباره کامپایل می‌شود — به قیمتِ یک تخصیصِ هیپ در هر صدا، هزینه‌ای که AFITِ خام هرگز نمی‌پردازد |
| spawn_blocking | `spawn_blocking` | کارِ یک کلوژرِ همگام (غیر-async) را به استخرِ ریسمانِ مسدودکننده‌ی جداگانه‌ی tokio می‌سپارد، به‌جایِ اجرا رویِ ریسمانِ کارگرِ async؛ یک `JoinHandle` برمی‌گرداند که مثلِ هر جایِ دیگر `await` می‌کنی — راهِ حلِ کارِ واقعاً سنگینِ پردازنده یا یک تماسِ مسدودکننده‌یِ اجتناب‌ناپذیر، نه هر تابعِ همگامی که فقط اتفاقاً سریع است |
| Handler | پردازشگر درخواست | تابعی که درخواست رسیده به یک مسیر را پردازش می‌کند |
| Connection pool | مخزن اتصال | مجموعه‌ای از اتصال‌های قابل‌بازاستفاده به پایگاه داده |
| Job queue | صف کار | صف کارهایی که پردازشگرها بعداً انجام می‌دهند |
| Cache | حافظه‌ی نهان | نسخه‌ی سریع و موقت داده برای کاهش هزینه‌ی خواندن |
| Destructor | تخریب‌گر | کدی که هنگام نابود شدن یک مقدار اجرا می‌شود؛ در Rust همان `Drop::drop` |
| RAII | گرفتن‌ـ‌همان‌ـ‌ساختن | منبع را هنگام ساخت بگیر و در تخریب‌گر آزاد کن؛ دامنه آزادش می‌کند، نه انضباط |
| Dereference | بازکردن ارجاع | رفتن به مقداری که ارجاع به آن اشاره می‌کند، با `*` |
| Auto-deref | بازکردن خودکار ارجاع | گذاشتن `*` توسط کامپایلر هنگام فراخوانی متد |
| Rc / Arc | اشاره‌گرِ هوشمندِ اشتراکی (`Rc`/`Arc`) | بیش از یک متغیر، هم‌زمان، مالکِ واقعیِ یک مقدارِ رویِ هیپ؛ کلون‌کردن‌شان دیتا را کپی نمی‌کند، فقط یک شمارنده‌ی ارجاع را یکی بالا می‌برد و مقدار فقط با dropِ آخرین دستگیره آزاد می‌شود. `Rc` تک‌ریسمانی است (شمارنده‌ای معمولی و غیراتمی)؛ `Arc` نسخه‌ی امنِ رشته‌ای است، با شمارنده‌ای اتمی — کندتر در هر کلون، ولی امن برایِ اشتراک بینِ ریسمان‌ها. هردو فقط `&T` می‌دهند، هرگز `&mut T` |
| Message passing | پیام‌رسانی | ریسمان‌ها به‌جایِ دست‌درازی به یک حافظه‌ی مشترک، مقدارهایِ مالکیت‌دار را برایِ هم می‌فرستند؛ مدلِ جایگزینِ `Arc<Mutex<T>>`. شعارش: «به‌جایِ اشتراکِ حافظه ارتباط برقرار نکن؛ با ارتباط‌برقرارکردن حافظه را به اشتراک بگذار» |
| Channel (`std::sync::mpsc`) | کانال | صفی که یک `Sender<T>` را به یک `Receiver<T>` وصل می‌کند؛ `.send()` مقدار می‌گذارد، `.recv()` (یا پیمایشِ مستقیمِ `Receiver`) به همان ترتیب برمی‌دارد. `mpsc::channel()` بدونِ‌کران است — `.send()` هرگز متوقف نمی‌شود؛ `mpsc::sync_channel(n)` آن را به `n` جا محدود می‌کند، و وقتی پر باشد `.send()` متوقف می‌شود تا گیرنده جا باز کند (پس‌فشار) |
| Sender / Receiver | فرستنده و گیرنده (`Sender`/`Receiver`) | دو نیمه‌ی یک کانال. `Sender` قابلِ `Clone` است — یکی به‌ازایِ هر ریسمانی که باید بفرستد، همه به همان `Receiver` تزریق می‌کنند (نیمه‌ی «چندتولیدکننده»یِ mpsc). `Receiver` قابلِ `Clone` نیست — دقیقاً یک مصرف‌کننده. `.recv()` (یا پیمایشگرِ `Receiver`) وقتی همه‌یِ `Sender`ها، شاملِ همه‌یِ کپی‌ها، پاک شده باشند، `Err`/پایان می‌دهد |
| Backpressure | پس‌فشار | راهِ یک سامانه برایِ گفتنِ «آهسته‌تر بفرست» به هر چیزی که برایش کار می‌فرستد، به‌جایِ صف‌کردنِ بی‌پایان یا از‌پا‌افتادن |
| Aliasing rule | قاعده‌ی هم‌نامی | هر تعداد قرض اشتراکی، یا دقیقاً یک قرض تغییرپذیر؛ هرگز هر دو با هم |
| Data race | مسابقه‌ی داده | دسترسی هم‌زمان دو ریسمان به یک حافظه که دست‌کم یکی می‌نویسد |
| Iterator invalidation | بی‌اعتبار شدن پیمایشگر | تغییر یک مجموعه در حین پیمایش آن |
| Borrow scope | دامنه‌ی قرض | از جایی که قرض گرفته می‌شود تا **آخرین استفاده**‌اش، نه تا پایان بلوک |
| Non-lexical lifetimes (NLL) | طول عمر غیرلغوی | قاعده‌ای که به قرض همان دامنه‌ی کوتاه‌ترِ مبتنی‌بر‌استفاده را می‌دهد |
| Two-phase borrow | قرض دومرحله‌ای | اجازه‌ای که `items.push(items.len())` را قانونی می‌کند |
| Slice | برش | نمایی قرضی از یک بازه‌ی پیوسته؛ دو کلمه: آغاز و طول |
| Fat pointer | اشاره‌گر چاق | ارجاعی که کلمه‌ی دومی هم همراه دارد (طول برش، یا vtable) |
| Smart pointer | اشاره‌گرِ هوشمند | ساختاری که مثلِ یک اشاره‌گر عمل می‌کند اما مالکِ چیزی هم هست که به آن اشاره می‌کند؛ `Box<T>` ساده‌ترینش است |
| Box | جعبه‌ی رویِ هیپ (`Box<T>`) | ساده‌ترین اشاره‌گرِ هوشمند: مقداری که رویِ هیپ جابه‌جا شده با یک مالکِ یکتا؛ اندازه‌اش هرگز به اندازه یا محتوایِ `T` بستگی ندارد — فقط به اینکه `T` اندازه‌دار است (یک کلمه) یا نه (اشاره‌گرِ چاق، بازهم ثابت) |
| Recursive type | نوعِ بازگشتی | نوعی که ممکن است خودش را در خودش نگه دارد؛ بدونِ واسطه اندازه‌ی نامتناهی دارد، پیچیدنِ فیلدِ بازگشتی در `Box<T>` درستش می‌کند |
| Expression tree | درختِ عبارت | نوعِ بازگشتیِ کلاسیک: `Num(f64)`، `Add(_, _)`، `Mul(_, _)` — هر گونه‌ی عملگر عملوندهایِ خودش را نگه می‌دارد |
| Boxed trait object | شیءِ صفتیِ جعبه‌ای (`Box<dyn Trait>`) | یک شیءِ صفتی که `Box` مالکش شده، پس می‌شود نگهش داشت، برگرداندش یا تویِ `Vec<Box<dyn Trait>>` گذاشتش |
| Weak | ارجاعِ ضعیف (Weak) | دستگیره‌ای غیرمالک به مقداری که با Rc/Arc مدیریت می‌شود؛ نگه‌داشتنش مقدار را زنده نگه نمی‌دارد و به شمارنده‌ی قوی اضافه نمی‌شود؛ تنها راهِ رسیدن به مقدار `.upgrade()` است که `Option<Rc<T>>` می‌دهد — `Some` تا وقتی یک مالکِ قوی هست، `None` بعد از اینکه آخرین‌شان رهایش کرد |
| Reference cycle | چرخه‌ی ارجاع | چند مقدار که با ارجاعِ قوی حلقه‌وار به هم اشاره می‌کنند، پس شمارنده‌ی هیچ‌کدام هرگز به صفر نمی‌رسد و `Drop::drop` هیچ‌وقت اجرا نمی‌شود — یک نشتِ حافظه‌ی واقعی، کاملاً در Rustِ ایمن |
| Rc::new_cyclic | سازنده‌ی `Rc::new_cyclic` | سازنده‌ای که پیش از تمام‌شدنِ ساختِ مقدار، یک `Weak<T>` به همان مقدار را در اختیارِ کلوژرش می‌گذارد؛ می‌گذارد فرزندهایِ یک مقدار، یک ارجاعِ ضعیفِ برگشتیِ کارآمد به آن داشته باشند، فقط یک‌بار، بدونِ نیاز به تغییرپذیریِ درونی |
| String literal | لیترال رشته | متن نوشته‌شده در کد؛ از نوع `&'static str` و همیشه یک نما |
| Unsized type | نوع بی‌اندازه | نوعی که اندازه‌اش هنگام کامپایل معلوم نیست، مثل `str` |
| Deref coercion | تبدیل ضمنی ارجاع | تبدیل خودکار `&String` به `&str` سر محل فراخوانی |
| Unicode scalar value | مقدار اسکالر یونیکد | یک کدپوینت؛ همان چیزی که `char` نگه می‌دارد |
| UTF-8 | یوتی‌اف-۸ | کدگذاری همیشگی رشته‌های Rust؛ حروف فارسی دو بایت |
| Continuation byte | بایت ادامه | هر بایت پس از بایت نخستِ یک کاراکتر چندبایتی |
| Char boundary | مرز کاراکتر | آفستی که یک کاراکتر واقعاً از آن شروع می‌شود؛ برش جای دیگر پنیک می‌کند |
| Combining mark | علامت ترکیبی | کاراکتری که کاراکتر پیش از خود را تغییر می‌دهد، مثل فتحه |
| Grapheme cluster | خوشه‌ی گرافیم | آنچه یک انسان «یک کاراکتر» می‌نامد؛ ممکن است چند اسکالر باشد |
