# واژه‌نامه‌ی یکدست SenPai

این واژه‌نامه مرجع ثابت درس‌هاست. در نخستین کاربرد هر اصطلاح، فارسی و انگلیسی را کنار هم می‌آوریم و بعد از معادل فارسی استفاده می‌کنیم.

| اصطلاح انگلیسی | فارسی معیار | توضیح کوتاه |
|---|---|---|
| Ownership | مالکیت | مسئولیت یکتای آزادسازی یک مقدار |
| Move | انتقال | واگذاری مالکیت از یک نام یا محدوده به دیگری |
| Borrowing | قرض‌گیری | دسترسی موقت از راه ارجاع بدون گرفتن مالکیت |
| Shared reference | ارجاع اشتراکی | دسترسی فقط‌خواندنی با `&T` |
| Mutable reference | ارجاع تغییرپذیر | مجوز انحصاری و موقت ویرایش با `&mut T` |
| Lifetime | طول عمر | بازه‌ای که یک ارجاع معتبر است |
| Trait | صفت (Trait) | قراردادی برای رفتار مشترک میان نوع‌ها |
| Future | کار آینده (Future) | محاسبه‌ای که شاید هنوز کامل نشده باشد |
| Runtime | محیط اجرا (Runtime) | سامانه‌ای که کارهای async را زمان‌بندی و اجرا می‌کند |
| Handler | پردازشگر درخواست | تابعی که درخواست رسیده به یک مسیر را پردازش می‌کند |
| Connection pool | مخزن اتصال | مجموعه‌ای از اتصال‌های قابل‌بازاستفاده به پایگاه داده |
| Job queue | صف کار | صف کارهایی که پردازشگرها بعداً انجام می‌دهند |
| Cache | حافظه‌ی نهان | نسخه‌ی سریع و موقت داده برای کاهش هزینه‌ی خواندن |

نام crate، بسته، نوع، شناسه، فرمان، API و متن واقعی خطای کامپایلر ترجمه نمی‌شود. در متن فارسی، این موارد با جهت چپ‌به‌راست نمایش داده می‌شوند.
