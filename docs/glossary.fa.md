# واژه‌نامه‌ی یکدست SenPai

این واژه‌نامه مرجع ثابت درس‌هاست. در نخستین کاربرد هر اصطلاح، فارسی و انگلیسی را کنار هم می‌آوریم و بعد از معادل فارسی استفاده می‌کنیم.

| اصطلاح انگلیسی | فارسی معیار | توضیح کوتاه |
|---|---|---|
| Ownership | مالکیت | مسئولیت یکتای آزادسازی یک مقدار |
| Move | انتقال | واگذاری مالکیت از یک نام یا محدوده به دیگری |
| Borrowing | قرض‌گیری | دسترسی موقت از راه ارجاع بدون گرفتن مالکیت |
| Shared reference | ارجاع اشتراکی | دسترسی فقط‌خواندنی با `&T` |
| Mutable reference | ارجاع تغییرپذیر | مجوز انحصاری و موقت ویرایش با `&mut T` |
| Lifetime | طول عمر | بازه‌ای که یک ارجاع معتبر است |
| Trait | صفت (Trait) | قراردادی برای رفتار مشترک میان نوع‌ها |
| Associated type | نوعِ وابسته | نوعِ جانشینی که یک صفت اعلام می‌کند و هر پیاده‌سازی دقیقاً یک‌بار پرش می‌کند |
| Future | کار آینده (Future) | محاسبه‌ای که شاید هنوز کامل نشده باشد |
| Runtime | محیط اجرا (Runtime) | سامانه‌ای که کارهای async را زمان‌بندی و اجرا می‌کند |
| Handler | پردازشگر درخواست | تابعی که درخواست رسیده به یک مسیر را پردازش می‌کند |
| Connection pool | مخزن اتصال | مجموعه‌ای از اتصال‌های قابل‌بازاستفاده به پایگاه داده |
| Job queue | صف کار | صف کارهایی که پردازشگرها بعداً انجام می‌دهند |
| Cache | حافظه‌ی نهان | نسخه‌ی سریع و موقت داده برای کاهش هزینه‌ی خواندن |
| Destructor | تخریب‌گر | کدی که هنگام نابود شدن یک مقدار اجرا می‌شود؛ در Rust همان `Drop::drop` |
| RAII | گرفتن‌ـ‌همان‌ـ‌ساختن | منبع را هنگام ساخت بگیر و در تخریب‌گر آزاد کن؛ دامنه آزادش می‌کند، نه انضباط |
| Dereference | بازکردن ارجاع | رفتن به مقداری که ارجاع به آن اشاره می‌کند، با `*` |
| Auto-deref | بازکردن خودکار ارجاع | گذاشتن `*` توسط کامپایلر هنگام فراخوانی متد |
| Aliasing rule | قاعده‌ی هم‌نامی | هر تعداد قرض اشتراکی، یا دقیقاً یک قرض تغییرپذیر؛ هرگز هر دو با هم |
| Data race | مسابقه‌ی داده | دسترسی هم‌زمان دو ریسه به یک حافظه که دست‌کم یکی می‌نویسد |
| Iterator invalidation | بی‌اعتبار شدن پیمایشگر | تغییر یک مجموعه در حین پیمایش آن |
| Borrow scope | دامنه‌ی قرض | از جایی که قرض گرفته می‌شود تا **آخرین استفاده**‌اش، نه تا پایان بلوک |
| Non-lexical lifetimes (NLL) | طول عمر غیرلغوی | قاعده‌ای که به قرض همان دامنه‌ی کوتاه‌ترِ مبتنی‌بر‌استفاده را می‌دهد |
| Two-phase borrow | قرض دومرحله‌ای | اجازه‌ای که `items.push(items.len())` را قانونی می‌کند |
| Slice | برش | نمایی قرضی از یک بازه‌ی پیوسته؛ دو کلمه: آغاز و طول |
| Fat pointer | اشاره‌گر چاق | ارجاعی که کلمه‌ی دومی هم همراه دارد (طول برش، یا vtable) |
| String literal | لیترال رشته | متن نوشته‌شده در کد؛ از نوع `&'static str` و همیشه یک نما |
| Unsized type | نوع بی‌اندازه | نوعی که اندازه‌اش هنگام کامپایل معلوم نیست، مثل `str` |
| Deref coercion | تبدیل ضمنی ارجاع | تبدیل خودکار `&String` به `&str` سر محل فراخوانی |
| Unicode scalar value | مقدار اسکالر یونیکد | یک کدپوینت؛ همان چیزی که `char` نگه می‌دارد |
| UTF-8 | یوتی‌اف-۸ | کدگذاری همیشگی رشته‌های Rust؛ حروف فارسی دو بایت |
| Continuation byte | بایت ادامه | هر بایت پس از بایت نخستِ یک کاراکتر چندبایتی |
| Char boundary | مرز کاراکتر | آفستی که یک کاراکتر واقعاً از آن شروع می‌شود؛ برش جای دیگر پنیک می‌کند |
| Combining mark | علامت ترکیبی | کاراکتری که کاراکتر پیش از خود را تغییر می‌دهد، مثل فتحه |
| Grapheme cluster | خوشه‌ی گرافیم | آنچه یک انسان «یک کاراکتر» می‌نامد؛ ممکن است چند اسکالر باشد |
| ZWNJ | نیم‌فاصله | `\u{200C}`؛ سه بایت، یک `char`، بدون عرض — چیدمان ستونی را می‌شکند |
| Normalization | نرمال‌سازی | یکسان‌سازی املای متن تا دو نوشتار یکسان برابر شمرده شوند |
| Display / Debug | نمایش / اشکال‌زدایی | `{}` برای کاربر، `{:?}` برای تو؛ دو صفت جدا برای دو مخاطب جدا |
| Tuple struct | ساختار تاپلی | ساختاری که فیلدهایش جای اسم، جایگاه دارند: `struct Meters(f64);` |
| Unit struct | ساختار واحد | ساختاری بدون هیچ فیلد؛ صفر بایت |
| Newtype pattern | الگوی newtype | پیچیدن یک نوع ساده در ساختار تاپلی تا سیستم نوع دو چیز را از هم تشخیص دهد |
| Refutable / irrefutable | ردشدنی / ردناشدنی | الگویی که ممکن است تطبیق نکند، در برابر الگویی که همیشه می‌کند |
| Diverging | واگرا | عبارتی که هرگز مقدار تولید نمی‌کند؛ نوعش `!` است |
| Panic | پنیک | شکست جبران‌ناپذیر؛ پشته را باز می‌کند و تخریب‌گرها را اجرا می‌کند |
| Unwinding | بازکردن پشته | کاری که پنیک به‌طور پیش‌فرض می‌کند: بالا رفتن از پشته و اجرای هر تخریب‌گر سرِ راه |
| Closure | کلوژر | تابعی که درجا نوشته و به‌عنوان مقدار پاس داده می‌شود، و می‌تواند متغیرهای اطرافش را بگیرد |
| Combinator | ترکیب‌گر | متدی که مقدارِ پیچیده‌شده را بدون بازکردنش دگرگون می‌کند |
| Eager / lazy | مشتاق / تنبل | `.unwrap_or(x)` همیشه `x` را ارزیابی می‌کند؛ `.unwrap_or_else(|| x)` فقط وقتی لازم باشد |
| Capture | گرفتن | نحوه‌ی دسترسیِ کلوژر به متغیرِ اطرافش: با ارجاعِ اشتراکی، ارجاعِ تغییرپذیر، یا با گرفتنِ کاملِ مالکیت |
| Fn / FnMut / FnOnce | سلسله‌مراتبِ traitهای کلوژر | چه کاری کلوژر با چیزی که گرفته انجام می‌دهد: `Fn` فقط می‌خواند، `FnMut` تغییرش می‌دهد، `FnOnce` از داخلش بیرون می‌بردش |
| Move closure | کلوژرِ `move` | کلوژری که همه‌چیزش را با گرفتنِ کاملِ مالکیت می‌گیرد، نه با ارجاع |
| Function pointer | اشاره‌گرِ تابع | نوعِ یک تابعِ ساده و بدونِ هیچ گرفتنی، وقتی به‌عنوانِ مقدار به‌کار می‌رود؛ مثل `fn(i32) -> i32` |
| Struct literal | عبارت ساخت ساختار | `Series { title, episodes }` — عبارتی که یک ساختار می‌سازد |
| Field init shorthand | کوته‌نویسی مقداردهی فیلد | نوشتن `title` به‌جای `title: title` وقتی متغیر همان نام را دارد |
| Struct update syntax | نحو به‌روزرسانی ساختار | `..other` — بقیه‌ی فیلدها را از آن یکی بردار |
| Partial move | حرکت جزئی | بیرون بردن یک فیلد از ساختار، که خودِ ساختار را غیرقابل‌استفاده می‌کند |
| Associated function | تابع وابسته | تابعی در `impl` بدون `self`، مثل `Series::new(...)` |
| Invariant | ناوردا | چیزی که یک نوع قول می‌دهد همیشه درباره‌ی مقدارهایش درست است |
| Enum | شمارشی | نوعی که دقیقاً یکی از چند شکل است و هر شکل داده‌ی خودش را دارد |
| Variant | گونه | یکی از آن شکل‌ها |
| Discriminant | شناسه‌ی گونه | برچسب پنهانی که می‌گوید مقدار کدام گونه است |
| Sum type | نوع جمعی | نامِ نظری همین ایده: «یکی از این‌ها»، در برابر «همه‌ی این‌ها» |
| Niche optimisation | بهینه‌سازی جای‌خالی | استفاده از یک مقدار ناممکن به‌عنوان شناسه؛ چرا `Option<Box<T>>` رایگان است |
| Null-pointer optimisation | بهینه‌سازی اشاره‌گر تهی | مشهورترین حالتِ بالا؛ `Option<bool>` هم یک بایت است |
| Pattern | الگو | شکلی که کامپایلر یک مقدار را با آن تطبیق می‌دهد |
| Arm | بازو | یک خط `الگو => عبارت` در یک `match` |
| Exhaustiveness | جامع بودن | اثبات کامپایلر که `match` همه‌ی حالت‌ها را پوشانده |
| Guard | نگهبان | شرط `if` روی یک بازو؛ در جامع بودن به حساب نمی‌آید |
| Range pattern | الگوی بازه‌ای | `1..=9` |
| Alternative | جایگزین | `a | b` — هرکدام از این‌ها |
| Wildcard | جانشین | `_` — هر چیزی، بدون نام |
| `@` binding | اتصال با `@` | هم تطبیق بده هم مقدار را زیر یک نام نگه دار |
| Unreachable arm | بازوی دست‌نیافتنی | بازویی که بازوی پیش‌تر همه‌اش را پوشانده؛ تقریباً همیشه خطای ترتیب |
| Amortized | مستهلک‌شده | هزینه‌ای که گاهی گران و بیشترِ وقت‌ها ارزان است و در کل چیزِ کوچکی می‌شود |
| Entry API | ای‌پی‌آیِ entry | جست‌وجویِ یک کلید و تصمیم درباره‌ی نبودش، در یک عملیات به‌جایِ دوبار جست‌وجو |
| Hasher | هشر | الگوریتمی که کلید را به عددی تبدیل می‌کند که هش‌مپ برایِ جاگذاری استفاده می‌کند |
| Hash flooding | سیلِ هش | ورودیِ عمداً ساخته‌شده برایِ برخوردِ عمدیِ کلیدها در یک باکتِ هش |
| Ring buffer | بافرِ حلقه‌ای | بلوکِ حافظه‌ای که دایره‌ای رفتار می‌شود؛ عبور از انتها به ابتدا برمی‌گردد |
| Priority queue | صفِ اولویت | ساختاری که فقط «بزرگ‌ترین/کوچک‌ترینِ فعلی» را ارزان می‌دهد |
| Double-ended queue | صفِ دو-سَر | صفی که از هر دو سر، ارزان پوش و پاپ می‌شود |
| Iterator | ایتریتور | هر چیزی که یک متد داشته باشد: `next(&mut self) -> Option<Self::Item>` |
| Iterator adapter | ترکیب‌گرِ ایتریتور | متدی که ایتریتور را در یکیِ تازه می‌پیچد؛ تنبل — فقط توصیف می‌کند، اجرا نمی‌کند |
| Consuming adapter | مصرف‌کننده | متدی که همه‌ی مقدارها را از خط‌لوله رد می‌کند و یک نتیجه‌ی نهاییِ غیرِایتریتور می‌سازد |
| FromIterator | صفتِ FromIterator | قراردادی که `.collect()` رویش جنریک است؛ هر نوعی که آن را پیاده کند هدفِ `.collect()` می‌شود |
| Short-circuiting | توقفِ زودهنگام | متوقف‌شدن به‌محضِ معلوم‌شدنِ جوابِ نهایی؛ اولین `Err` در جمع‌آوریِ `Result`ها دقیقاً همین کار را می‌کند |
| Lazy iterator | ایتریتورِ تنبل (ارزیابیِ تقاضامحور) | آداپتور به‌تنهایی کاری نمی‌کند؛ هر عنصر یکی‌یکی، فقط وقتی چیزی پایین‌دست `.next()` بخواهد، از کلِ زنجیره عبور می‌کند |
| Zero-cost abstraction | انتزاعِ رایگان | سازه‌ای سطح‌بالا که دقیقاً به‌اندازه‌ی نسخه‌ی دستی‌اش کار انجام می‌دهد؛ نوشتنِ تعریفی‌اش هزینه‌ی اجراییِ اضافه‌ای ندارد |
| Infinite iterator | ایتریتورِ بی‌نهایت | ایتریتوری بدونِ پایانِ معلوم؛ امن است چون هیچ‌چیز اجرا نمی‌شود تا مصرف‌کننده‌ای محدود مثلِ `.take()` مقدار بخواهد |
| Generator | مولد | شرحِ چگونگیِ ساختنِ مقدارِ بعدی از رویِ مقدارِ فعلی، نه فهرستی از پیش نوشته‌شده |
| `.by_ref()` | قرضِ موقتِ ایتریتور | قرضِ موقتِ یک ایتریتور، تا خودش بعدش هنوز قابلِ‌استفاده بماند |
| Mid-chain `.collect()` trap | تله‌ی `.collect()`ِ میانی | جمع‌آوری در وسطِ زنجیره‌ای که قرار بود ادامه پیدا کند؛ یک تخصیص و یک عبورِ کامل که تنبلی جلویش را می‌گرفت |

نام crate، بسته، نوع، شناسه، فرمان، API و متن واقعی خطای کامپایلر ترجمه نمی‌شود. در متن فارسی، این موارد با جهت چپ‌به‌راست نمایش داده می‌شوند.
