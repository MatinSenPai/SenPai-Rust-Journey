# Module 1 — Networking & protocols

Phase 3 built a hand-rolled HTTP parser and an `axum` REST API; Phase 4
added gRPC and GraphQL. This module fills in the protocol landscape
around those choices — why HTTP evolved the way it did, when you'd reach
for a WebSocket instead of polling, what a load balancer/reverse
proxy/API gateway actually each do (they're not synonyms), and how to
choose between REST, GraphQL, gRPC, and friends with more than gut feel.
