# ماژول ۳ — کشینگ و پرفورمنس

درس Redis تو فاز ۴ الگوی cache-aside رو برای یک اندپوینت یاد داد. این ماژول زاویه دید رو بازتر می‌کنه: بقیه‌ی استراتژی‌های کشینگ که اونجا استفاده نکردی و زمانِ استفاده‌شون، سیاست‌های انقضای کش (eviction policies)، شبکه‌های CDN، و اعداد و ارقامِ ملموس تاخیر (latency numbers) که هر مهندس بک‌اندی باید حفظ باشه تا بتونه روی تخته‌واستبرد در مورد یه سیستم بحث کنه.
