# Module 7 — Applied system design

Modules 1-6 gave you vocabulary and patterns. This module is where you
actually use them: five classic "design X" interview questions, each
built for real — not just discussed on a whiteboard — using the exact
stack this repo already taught (`axum`, Postgres, Redis, WebSockets).
Every lesson's `README.md` starts with the same structure a real system
design interview does: requirements, a naive first design, then the
scaling problems and how to solve them — before you write a line of code.
