# ماژول ۷ — طراحی سیستم کاربردی

ماژول‌های ۱ تا ۶ واژگان و الگوها رو بهت دادن. این ماژول جاییه که رسماً ازشون استفاده می‌کنی: ۵ تا سؤال کلاسیک مصاحبه "طراحی سیستم X"، که همه‌شون واقعاً ساخته می‌شن — نه فقط بحث روی تخته‌واستبرد — با استفاده از همون تکنولوژی‌هایی که تو این دوره یاد گرفتی (`axum`، Postgres، Redis، WebSockets).
هر درس تو این ماژول با همون ساختاری شروع می‌شه که تو مصاحبه‌های واقعی طراحی سیستم می‌بینی: نیازمندی‌ها، یه طرح اولیه ساده، بعد مشکلات مقیاس‌پذیری و نحوه حل اونا — قبل از اینکه حتی یه خط کد بنویسی.
