# ماژول ۶ — مبانی DevOps و کلود

درس `docker-compose-and-ci` تو فاز ۴ بهت یه Dockerfile و یه خط‌لوله CI داد. این ماژول لایه‌ی زیرین و دور و برِ اونه: کانتینر واقعاً چیه (یه VM سبک نیست!)، کوبرنیتیز به چه دردی می‌خوره و کی پروژه واقعاً بهش نیاز داره، لیست استراتژی‌های دیپلوی فراتر از فقط "ریستارت کردن"، و قوانین 12-Factor که بهت میگه چرا درس‌های همین دوره `DATABASE_URL` رو از متغیرهای محیطی می‌خوندن نه هاردکدشده تو کد.
