# Module 6 — DevOps & cloud fundamentals

Phase 4's `docker-compose-and-ci` lesson gave you one Dockerfile and one
CI pipeline. This module is the layer underneath and around that:
what a container actually is (not a lightweight VM), what Kubernetes is
for and when a project actually needs it, the real menu of deployment
strategies beyond "just redeploy," and the Twelve-Factor App rules that
quietly explain *why* this repo's own lessons read `DATABASE_URL` from
the environment instead of hardcoding it.
