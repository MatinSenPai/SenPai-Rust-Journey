# سفر SenPai برای یادگیری Rust

یک دوره‌ی کامل و خودآموزِ زبان Rust؛ از همین سؤال که "اصلاً زبان کامپایل‌شده یعنی چی؟" تا ساختنِ یه بک‌اندِ واقعی و آماده‌ی پروداکشن. این مسیر کلاً واسه متین ساخته شده؛ یه برنامه‌نویسِ Python/Django که هنوز هیچ تجربه‌ای تو برنامه‌نویسی سیستم نداره.

قرار نیست فقط با سینتکس و دستوراتِ زبان Rust آشنا بشی. هدف اصلی اینه که تو پایانِ این مسیر، مثل یه مهندس نرم‌افزارِ ارشد فکر کنی: مفاهیمِ مالکیت و مموری رو بدونِ نیاز به سیستم زباله‌روب (Garbage Collector) تحلیل کنی، یه سرویسِ بک‌اندِ واقعی با API، دیتابیس، حافظه‌ی کش، صفِ کارها و سیستم احراز هویت بسازی، دلایل انتخاب‌ها و بده‌بستان‌های طراحی سیستم رو توضیح بدی، و یه پروژه‌ی نهاییِ رزومه‌ای داشته باشی که واقعاً تو بازار کار ارزش داشته باشه.

## تازه واردی و تا حالا Rust ننوشتی؟

اول از همه فایلِ [`docs/START-HERE.fa.md`](docs/START-HERE.fa.md) رو بخون. این راهنمایِ ده‌دقیقه‌ای، راه‌اندازیِ Rust و شیوه‌ی پیش‌رفتن تو تک‌تکِ درس‌ها رو قدم‌به‌قدم بهت توضیح میده.

## ساختار این مخزن آموزشی

- `docs/`: نقطه‌ی شروع، ستاپ و راه‌اندازی، قراردادها، واژه‌نامه و اسناد ADR.
- `phase0-setup/` تا `phase4-backend-advanced/`: دروسِ اصلیِ دوره به ترتیب فصل‌ها.
- `phase5-system-design-mastery/`: طراحی سیستم، بررسی پروتکل‌ها، ذخیره‌سازی تو مقیاس بالا و مبانی کلود.
- `side-quests/`: مأموریت‌های جانبی و پروژه‌های کوچیکِ تلگرام، انیمه، مانگا و وب‌تون واسه تبدیل تئوری به مهارت.
- `capstone-taskforge/`: پروژه‌ی پایانی TaskForge؛ یه موتورِ صفِ کار روی Postgres، دقیقاً از همون دسته‌بندیِ مسائلی که Celery، Sidekiq و BullMQ حل می‌کنن.
- `PROGRESS.fa.md`: چک‌لیستِ دستیِ کُلِ مسیر.
- `web-ui/`: رابط کاربریِ لوکال واسه مطالعه و ثبتِ پیشرفت (این خود ابزاره، نه محتوای آموزشی).

## شروع سریع

```sh
# ستاپ یک‌باره؛ جزئیات تو فایل docs/setup-guide.fa.md
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

cargo build --workspace
```

بعدش فایلِ `phase0-setup/README.fa.md` رو باز کن و از درسِ اول شروع کن.

## مطالعه تو مرورگر

یه رابط وبِ سبک و لوکال کُلِ این مخزن رو نشون میده و پایانِ هر درس رو برات ثبت می‌کنه:

```sh
cargo run -p course-ui
```

سرویس روی `http://127.0.0.1:5000` اجرا می‌شه و مرورگر رو باز می‌کنه. اولین اجرا چند ثانیه وقت صرف کامپایل می‌کنه. با `Ctrl-C` می‌تونی متوقفش کنی.

| گزینه | کاربرد |
|---|---|
| `--no-open` | سرور رو بدون بازکردنِ خودکارِ مرورگر اجرا می‌کنه |
| `--root <path>` | یه کپیِ دیگه‌ای از این دوره رو نمایش میده |

```sh
cargo run -p course-ui -- --no-open
```

### امکانات رابط وب (UI)

- زبان فارسی به عنوان پیش‌فرض و انگلیسی زبان دوم، با حفظِ مسیر هنگام تغییر زبان.
- داشبوردی شامل اولين درسِ ناتمام، درصد پیشرفت و نقشه‌ی راه.
- درخت تودرتوی فازها، بخش‌ها و درس‌ها که شاخه‌ی جاری رو باز نگه می‌داره.
- صفحه‌ی درس شامل README و در نهایت راه‌حلِ مرجع، پشتِ یک کلیک.
- زیرِ هر درس یک **خودارزیابی**: پله‌های تمرینی که انجام داده‌ای را تیک بزن، بگو چقدر برایت جا افتاده، و برای خودت یادداشت بگذار. هیچ‌کدام نمره نمی‌خورد؛ همین‌ها ورودیِ صفحه‌ی پیشرفت‌اند.
- **صفحه‌ی پیشرفت** روی `/fa/progress`: درصدِ کلی و فاز به فاز، روزهای پشت‌سرهم، تخمینِ زمان، تازه‌ترین درس‌هایی که تمام کرده‌ای، و یک **جدولِ تسلط بر مفاهیم** که از روی [`docs/concept-map.toml`](docs/concept-map.toml) ساخته می‌شود — تا ببینی کدام مفهوم‌های Rust واقعاً مالِ تو شده‌اند، نه اینکه چند تا تیک خورده.
- **تمِ روشن و تاریک** با یک دکمه در نوارِ بالا، که یادش می‌ماند.
- جست‌وجوی سمت سرور و ثبت پایان درس یا رفتن مستقیم به درس بعدی.
- صفحه‌های بخش `docs/` و ADRها قابل مطالعه‌ان ولی چون درس نیستن چک‌باکس ندارن.

محتوا تو حافظه‌ی کش نمی‌مونه؛ فایل README رو ادیت کن یا درسی اضافه کن و با رفرش کردنِ صفحه نتیجشو ببین.

### محل ذخیره‌ی پیشرفت

پیشرفت تو فایل `.course-progress.json` تو ریشه‌ی پروژه ذخیره می‌شه و کلیدِ هر درس، مسیر پوشه‌ی اونه. Git این فایل رو نادیده می‌گیره و فقط روی سیستمِ خودت می‌مونه؛ با پاک کردنش می‌تونی پیشرفتت رو از نو شروع کنی.

این فایل منبع اصلیِ رابط وب هستش. فایلِ [`PROGRESS.fa.md`](PROGRESS.fa.md) فهرستِ دستی و فرعیه و سرور تغییرش نمی‌ده؛ بنابراین اگه هر دو رو دستی به‌روز کنی، ممکنه با هم هماهنگ نباظرن. دلیل این تصمیم تو سندِ [`docs/adr/0001-web-ui-progress-state.fa.md`](docs/adr/0001-web-ui-progress-state.fa.md) ثبت شده.

### اگه پورت ۵۰۰۰ اشغال بود

پورت ثابت مونده تا بوک‌مارکِ مرورگرت همیشه پایدار باشه. سرور به‌جای انتخاب پورت دیگه، با پیام `could not bind 127.0.0.1:5000` خارج می‌شه.

تو PowerShell پروسه‌ی مربوط به این پورت رو پیدا کن و بستش، بعد رابط وب رو دوباره اجرا کن:

```powershell
Get-NetTCPConnection -LocalPort 5000 -State Listen
cargo run -p course-ui
```

استفاده از رابط وب اختیاریه؛ تموم درس‌ها رو می‌تونی به صورت فایل‌های Markdown تو محیط VS Code یا GitHub هم بخونی.
