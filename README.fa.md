# سفر SenPai برای یادگیری Rust

یک دوره‌ی کامل و خودآموز Rust؛ از این پرسش که «زبان کامپایل‌شده چیست؟» تا ساخت یک بک‌اند آماده‌ی استفاده‌ی واقعی. این مسیر برای متین ساخته شده؛ برنامه‌نویس Python/Django که هنوز تجربه‌ای در برنامه‌نویسی سیستم ندارد.

قرار نیست فقط با دستور زبان Rust آشنا شوی. هدف این است که در پایان مثل یک مهندس نرم‌افزار فکر کنی: مالکیت و حافظه را بدون زباله‌روب (Garbage Collector) تحلیل کنی، یک سرویس بک‌اند با API، پایگاه داده، حافظه‌ی نهان، صف و احراز هویت بسازی، دلیل انتخاب‌ها و بده‌بستان‌های طراحی را توضیح بدهی و یک پروژه‌ی نهایی قابل ارائه در بازار کار داشته باشی.

## تازه واردی و Rust ننوشته‌ای؟

ابتدا [`docs/START-HERE.md`](docs/START-HERE.md) را بخوان. این راهنمای ده‌دقیقه‌ای، راه‌اندازی Rust و شیوه‌ی پیش‌رفتن در هر درس را قدم‌به‌قدم توضیح می‌دهد.

## ساختار مخزن

- `docs/`: نقطه‌ی شروع، setup، قرارداد‌ها، واژه‌نامه و ADRها.
- `phase0-setup/` تا `phase4-backend-advanced/`: دوره‌ی اصلی به‌ترتیب.
- `phase5-system-design-mastery/`: طراحی سیستم، پروتکل‌ها، ذخیره‌سازی در مقیاس و رایانش ابری.
- `side-quests/`: پروژه‌های کوچک تلگرام، انیمه، مانگا و وب‌تون برای تبدیل مفهوم به مهارت.
- `capstone-taskforge/`: پروژه‌ی اصلی TaskForge؛ یک موتور صف کار روی Postgres، از همان خانواده‌ی مسئله‌هایی که Celery، Sidekiq و BullMQ حل می‌کنند.
- `PROGRESS.md`: checklist دستی کل مسیر.
- `web-ui/`: UI محلی برای مطالعه و ثبت پیشرفت، نه محتوای آموزشی.

## شروع سریع

```sh
# setup یک‌باره؛ جزئیات در docs/setup-guide.md
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

cargo build --workspace
```

سپس `phase0-setup/README.md` را باز کن و از درس یک شروع کن.

## مطالعه در مرورگر

رابط وب سبک و محلی، کل مخزن را نمایش می‌دهد و پایان هر درس را برایت ثبت می‌کند:

```sh
cargo run -p course-ui
```

سرویس روی `http://127.0.0.1:5000` اجرا می‌شود و مرورگر را باز می‌کند. نخستین اجرا چند ثانیه صرف کامپایل می‌کند. با `Ctrl-C` متوقفش کن.

| گزینه | کاربرد |
|---|---|
| `--no-open` | سرور را بدون بازکردن مرورگر اجرا می‌کند |
| `--root <path>` | checkout دیگری از دوره را نمایش می‌دهد |

```sh
cargo run -p course-ui -- --no-open
```

### امکانات UI

- فارسی پیش‌فرض و انگلیسی زبان دوم، با حفظ مسیر هنگام تغییر زبان.
- داشبوردی با اولین درس ناتمام، درصد پیشرفت و نقشه‌ی راه.
- درخت تودرتوی فازها، بخش‌ها و درس‌ها که شاخه‌ی جاری را باز نگه می‌دارد.
- صفحه‌ی درس با README، سپس ایست بازرسی و بعد راه‌حل قفل‌شده.
- جست‌وجوی سمت سرور و ثبت پایان درس یا رفتن مستقیم به درس بعدی، بدون JavaScript.
- صفحه‌های `docs/` و ADR قابل مطالعه‌اند ولی چون درس نیستند checkbox ندارند.

محتوا در حافظه‌ی نهان نمی‌ماند؛ README را ویرایش کن یا درسی بیفزا و با تازه‌کردن صفحه نتیجه را ببین.

### محل ذخیره‌ی پیشرفت

پیشرفت در فایل `.course-progress.json` در ریشه‌ی مخزن ذخیره می‌شود و کلید هر درس، مسیر پوشه‌ی آن است. Git این فایل را نادیده می‌گیرد و فقط روی دستگاه تو می‌ماند؛ با حذفش می‌توانی پیشرفت را از نو آغاز کنی.

این فایل منبع اصلی رابط وب است. [`PROGRESS.md`](PROGRESS.md) فهرست دستی و فرعی است و سرور آن را تغییر نمی‌دهد؛ بنابراین اگر هر دو را دستی به‌روز کنی، ممکن است با هم هماهنگ نمانند. دلیل این تصمیم در [`docs/adr/0001-web-ui-progress-state.md`](docs/adr/0001-web-ui-progress-state.md) ثبت شده است.

### اگر درگاه ۵۰۰۰ اشغال است

درگاه ثابت مانده تا نشانک مرورگر پایدار باشد. سرور به‌جای انتخاب درگاهی دیگر، با پیام `could not bind 127.0.0.1:5000` خارج می‌شود.

در PowerShell، فرایند مربوط به این درگاه را پیدا کن و فقط همان فرایند را متوقف کن؛ سپس رابط وب را دوباره اجرا کن:

```powershell
Get-NetTCPConnection -LocalPort 5000 -State Listen
cargo run -p course-ui
```

رابط وب اختیاری است؛ همه‌ی درس‌ها را می‌توانی به‌صورت Markdown در GitHub یا ویرایشگر هم بخوانی.

