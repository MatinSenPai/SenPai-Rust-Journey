# ایست بازرسی

1. با `LIMIT 20 OFFSET 100000` و یک ایندکس عالی، Postgres پیش از برگرداندن ۲۰ ردیف چه کاری انجام می‌دهد؟ چرا ایندکس آن را ارزان‌تر می‌کند اما `O(limit)` نمی‌کند؟
2. چهار ردیف، صفحهٔ اولِ offset با اندازهٔ ۲، یک insert در بالا، بعد صفحهٔ دوم: کدام ردیف دوبار برمی‌گردد؟ حذف میان دو درخواست چه چیزی را جا می‌اندازد؟
3. اگر cursor فقط `created_at` باشد و پنج ردیف زمان برابر داشته باشند، پایان صفحه در میانهٔ آن‌ها با `<` و با `<=` چه خطایی می‌سازد؟ `id` چه خاصیتی را برمی‌گرداند؟
4. `(created_at, id) < ($1, $2)` را با `OR` و `AND` باز کن. چرا ترتیب ستون‌ها باید با `ORDER BY` یکسان باشد؟
5. چرا token از `timestamp_micros` استفاده می‌کند، نه nanosecond؟ در رفت‌وبرگشت `TIMESTAMPTZ` چه مرزی ممکن است خراب شود؟
6. اگر محصول «پرش به صفحهٔ ۳۷» و «صفحهٔ ۳ از ۴۱۲» بخواهد، برای هر کدام چه بهایی در keyset می‌دهی و چه الگویی لازم می‌شود؟
