# ماژول ۱ — شبکه و HTTP از صفر

قبل از اینکه اصلاً بخوای `axum` رو وارد کنی، ببین خودِ `axum` روی چی ساخته شده. انتزاعِ `Request`/`Response` تو هر فریم‌ورکی، روی یه سوکتِ TCP و یه پروتکلِ متنی نشسته که می‌تونی با چشمِ خودت بخونیش — این ماژول هر دوتاش رو با دست می‌سازه، تا ماژولِ فریم‌ورک که دقیقاً بعدِ این میاد، به‌جای اینکه یه چیزِ مرموز به‌نظر برسه، بشه «همینِ الان، فقط اتوماتیک‌شده».

   — متدها، کدهای وضعیت (status codes)، هدرها، content negotiation، keep-alive، و رمزگذاریِ chunked: همون بخش‌هایی از اسپک که هر فریم‌ورکی فرض می‌کنه از قبل بلدشونی.

تا آخرِ این ماژول، `Router` و extractorهای `axum` تو ماژولِ بعدی برات یه میان‌بر برایِ دقیقاً همین کار به‌نظر می‌رسن، نه یه چیزِ کاملاً جدا.
