# ماژول ۱ — شبکه و HTTP از صفرِ مطلق

قبل از اینکه بری سراغ فریم‌ورکِ `axum` (تو ماژول بعدی)، اول باید ببینی واقعاً روی چی بنا شده: یه سوکت (socket) خامِ TCP و یه پروتکل مبتنی بر متن. تا الان هر درخواستی (request) که تو ویوهای جنگو هندل می‌کردی، فرضش بر این بود که یه سرورِ WSGI از قبل این کارهای پایه رو برات انجام داده — اما این ماژول قراره یک بار هم که شده این کار رو با دستای خودت برات انجام بده، تا وقتی با ویژگی‌هایی مثل مسیریابی (routing)، اکسترکتورها و هندلرهای `axum` روبرو شدی، دیگه برات مثل یه جادوی غیرقابل‌فهم به نظر نرسن.

1. [۰۱ — سرور اکوی TCP (TCP echo server)](01-tcp-echo-server/README.fa.md) — کار با `TcpListener`، `TcpStream`، و اون حلقه‌ی خوندن/نوشتن (read/write loop) که هر سرور سطح بالاتری دقیقاً روی همون ساخته می‌شه.
2. [۰۲ — پارسر HTTP دست‌ساز](02-hand-rolled-http-parser/README.fa.md) — پارس کردن و استخراجِ خطِ درخواست (request line) و هدرها از دلِ بایت‌های خام، اونم کلاً با دست.

تا آخرِ این ماژول تو دقیقاً و مو به مو می‌دونی که یه فریم‌ورک وب وقتی داری `app.route@` یا `()Router::new` رو صدا می‌زنی، اون زیر داره چیکار می‌کنه — تو ماژولِ بعدی `axum` رو می‌دیم دستت تا دیگه از انجام دادنِ دستیِ این کارا راحت بشی.
