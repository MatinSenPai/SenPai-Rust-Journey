# ماژول ۸ — مدیریتِ خطا، ردیابی و تست در مقیاس

آخرین ماژولِ فازِ ۳ همون چیزیه که هر چی قبلش اومده رو قابلِ‌اجرا (operable) می‌کنه: یه شکلِ یکدست برایِ هر پاسخِ خطا، راهی برایِ دنبال‌کردنِ یه درخواست از پشتِ هر خطِ لاگی که لمسش می‌کنه، و تست‌هایی که رویِ یه دیتابیسِ واقعی و یک‌بارمصرف اجرا می‌شن، نه اینکه به یه mock اعتماد کنن. این ماژول با تنها قابلیتِ `axum`ی که هیچ ماژولِ صرفاً-RESTی تا الان بهش نپرداخته تموم می‌شه: یه اتصالی که باز می‌مونه.
