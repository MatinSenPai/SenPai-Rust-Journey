# ماژول ۲ — فریم‌ورک `axum` و طراحی REST API

ماژول ۱ از صفرِ صفر، با استفاده از بایت‌های خام یه سرور HTTP رو ساخت. این ماژول قراره همون درک رو تو ترکیب با `axum` به کار بگیره — `axum` همون فریم‌ورکِ غیرهمگامی (async) هست که کلِ این دوره‌ی آموزشی از اینجا به بعد روش بنا می‌شه، و دقیقاً همون رابطه‌ای رو با لایه‌ی زیرینش داره که جنگو با پروتکلِ خامِ WSGI داره.

۱. [۰۱ — مسیریابی (Routing)، هندلرها، استخراج‌کننده‌ها (extractors)](01-routing-handlers-extractors/README.fa.md)
   — کلاسِ `Router`، هندلرهای غیرهمگام (async handlers)، و استخراج‌کننده‌هایی مثل `Path`/`Json`/`State` که قراره جایگزین پارس‌کردنِ دستیِ درخواست بشن.
۲. [۰۲ — نوشتنِ extractor خودت](02-writing-your-own-extractor/README.fa.md)
   — پیاده‌سازیِ `FromRequestParts` با دست، برایِ روزی که extractorهایِ آماده جوابگویِ چیزی که هندلرت واقعاً لازم داره نیستن.
۳. [۰۳ — عملیاتِ CRUD رو کاتالوگ انیمه (داخل حافظه)](03-anime-catalog-crud-in-memory/README.fa.md)
   — یه REST API کامل شامل عملیات‌های ساختن/خوندن/آپدیت/پاک‌کردن، که داده‌ها رو تو مموری ذخیره می‌کنه؛ دقیقاً همین قالب رو تو ماژول ۵ با اتصال به دیتابیسِ واقعیِ Postgres قراره دوباره از نو بسازی.
۴. [۰۴ — `tower::Service`/`Layer`: میان‌افزار با دست](04-tower-service-and-layer-middleware/README.fa.md)
   — اینکه یه `Layer` زیرِ پوستِ `.layer(...)` واقعاً چیه، از صفر ساخته‌شده، قبل از اینکه درسِ بعدی یه دونه‌ی آماده دستت بده.
۵. [۰۵ — مفهوم CORS و اتصال به فرانت‌اند](05-cors-and-frontend-integration/README.fa.md)
   — سیاستِ same-origin که مرورگرها تحمیل می‌کنن، درخواست‌هایِ پیش‌پروازِ `OPTIONS`، و ابزار `CorsLayer` که برای محیط‌های توسعه و پروداکشن فرق می‌کنه — همه‌ی اینا بدون نیاز به مرورگر و از طریق `oneshot` تست می‌شن.

تا آخرِ این ماژول، تو می‌تونی یه REST API واقعی، با کدهای وضعیتِ درست‌وحسابی، بدنه‌ی خطای فرمتِ JSON، و میان‌افزارِ خودت رو بیاری بالا — البته هنوز بدون دیتابیس؛ دیتابیس می‌مونه واسه ماژولِ ۵.
