# مأموریت‌های جانبی (Side Quests)

مینی‌پروژه‌های جذاب و انگیزشی — دقیقاً همون نقطه‌ای که مفاهیم بنیادی دیگه حالت انتزاعی بودن خودشون رو از دست می‌دن. هر کدوم از این مأموریت‌ها فقط به مهارت‌هایی نیاز دارن که تا همون فاز قبلیش بازشون کردی؛ هیچ‌کدومشون جلوی رفتنت به فاز بعدی رو نمی‌گیرن، اما بی‌خیال شدنشون یعنی بی‌خیال شدنِ جذاب‌ترین قسمتِ این پروژه.

| مأموریت جانبی | بازشده بعد از | چیزایی که استفاده می‌کنه |
|---|---|---|
| [۰۱ — ابزار CLI نقل‌قول‌های انیمه](sq-01-anime-quote-cli/README.fa.md) | فاز ۱ | استراکت‌ها/انوم‌ها، تطبیق الگو (pattern matching)، نوع `Vec`، و `Option`/`Result` |
| [۰۲ — ربات تلگرامی کوییز](sq-02-telegram-quiz-bot/README.fa.md) | فاز ۲ | برنامه‌نویسی async/`tokio`، کتابخونه `teloxide`، کلوژرها، مدیریت خطا |
| [۰۳ — سرویس اعلان وب‌تون](sq-03-webtoon-notifier-service/README.fa.md) | فاز ۳ | فریم‌ورک `axum`، `sqlx`/Postgres، بررسی‌های زمان‌بندی‌شده، صدازدن ربات فاز ۲ |
| [۰۴ — API تجمیع‌کننده انیمه/مانگا](sq-04-anime-manga-aggregator-api/README.fa.md) | فاز ۴ | سیستم کشینگ، محدودکننده نرخ (rate limiting)، نظارت‌پذیری (observability) |

این پروژه‌ها دقیقاً از همون جنس پروژه‌های کوچیک، کامل و جذابی هستن که ارزششو دارن کنار پروژه‌ی پایانی TaskForge تو رزومه یا پورتفولیوت بهشون لینک بدی — اونا تنوعِ کارت (کارهای باحال و محصول‌محور) رو کنار عمقِ TaskForge (کارهای زیرساختی و تجاری) نشون می‌دن.
