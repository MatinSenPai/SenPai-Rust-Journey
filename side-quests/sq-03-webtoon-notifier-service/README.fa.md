# مأموریت جانبی ۳ — سرویس اعلان وب‌تون

همه این حس رو می‌شناسیم: مانگا یا وب‌تونی که دنبال می‌کنی چپتر جدیدش میاد و تو ۳ روز بعد می‌فهمی چون یادت رفته بود چک کنی. این مأموریت جانبی سرویسی رو می‌سازه که اون مشکل رو حل می‌کنه — همون "چک‌پوینت انگیزشی" که README فاز ۳ دقیقاً بعد درس CRUD axum بهش اشاره کرد، و پیش‌نمایشی از ماژول کارهای پس‌زمینه است که تو فاز ۴ منتظرت بود.

این شامل همه‌چیز از ماژول axum فاز ۳ (مسیریابی، اکسترکتورها، استیتِ محافظت‌شده با `Mutex` تو حافظه، مدیریت خطای `IntoResponse`) به همراه اولین تجربه از **جاب پس‌زمینه‌ی زمان‌بندی‌شده** هست — یه تسکِ `tokio::spawn` که رو یه تایمر بیدار می‌شه، کار انجام می‌ده، و یافته‌هاش رو لاگ می‌کنه، و تمام مدتی که پروسه بالاست کنار سرور HTTPت ران می‌شه.

## چی کار می‌کنه

یه REST API کوچیک برای پیگیری وب‌تون‌هایی که دنبال می‌کنی، به همراه یه بررسی‌کننده پس‌زمینه (poller):

```
POST /webtoons               دنبال کردن یک وب‌تون (عنوان + چپتری که الان روشی)
GET  /webtoons                لیست تمام چیزایی که دنبال می‌کنی
POST /webtoons/{id}/check     چک کردن فوری یک وب‌تون همین الان، به درخواست تو
```

...و تمام مدتی که سرور بالاست، یه تسک پس‌زمینه که همون منطق "چک کردن برای چپتر جدید" رو واسه *تمام* وب‌تون‌های دنبال‌شده رو یه تایمر صدا می‌زنه، و هر وقت چیز جدیدی پیدا کنه لاگ می‌زنه (با `tracing`).

## ساختار

- `src/lib.rs` — همه‌چیز: `Webtoon`، `WebtoonStore` (کاتالوگ محافظت‌شده با `Mutex` تو حافظه)، Traitِ `ChapterChecker` و سه پیاده‌سازیش، `check_all_webtoons` (یک دورِ "همه‌چی رو چک کن، تغییرات رو آپدیت کن")، `spawn_notifier` (حلقه اصلی جاب پس‌زمینه)، و هندلرها/روتر axum.
- `src/main.rs` — همه‌چی رو به هم وصل می‌کنه و سرور رو استارت می‌زنه.
- `tests/` — تست‌های استور، نوتیفایر و API.

## وظیفه‌ی تو

چهار تا `!()todo` رو کامل کن:
1. **`check_all_webtoons`** — واسه هر وب‌تون دنبال‌شده، از چکر بپرس آیا چپتر جدیدی هست؛ اگه شماره چپتر گزارش‌شده *اکیداً بزرگتر* از ذخیره‌شده بود، استور رو آپدیت کن، رویداد رو ثبت کن و لاگ بزن.
2. **`check_webtoon`** — هندلر `POST /webtoons/{id}/check`.
3. **`follow_webtoon`** — هندلر `POST /webtoons`.
4. **`app`** — متصل کردن دو مسیر به هندلرهاشون.
