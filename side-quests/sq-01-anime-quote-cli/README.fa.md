# مأموریت جانبی ۱ — ابزار CLI نقل‌قول‌های انیمه

اولین برنامه‌ی واقعی و مستقلِ تو — همه‌چیز از فاز ۱ (استراکت‌ها، `Vec`، `Option`، اسلایس‌های رشته‌ای، تطبیق الگو) دست به دست هم دادن تا روی چیزی کار کنن که واقعاً از ران کردنش لذت می‌بری. هیچ مفهوم جدیدی اینجا نیست؛ این تمرین تعمداً واسه تثبیتِ یادگیریه، نه یه درس جدید.

## چی کار می‌کنه

یه ابزار خط‌فرمان روی یه کالکشنِ توکار و کوچیک از دیالوگ‌های انیمه:

```sh
cargo run -p sq-01-anime-quote-cli                      # چاپ یک نقل‌قول تصادفی
cargo run -p sq-01-anime-quote-cli -- list               # لیست کردن تمام نقل‌قول‌ها
cargo run -p sq-01-anime-quote-cli -- anime "One Piece"   # دیالوگ‌های مربوط به اون انیمه
cargo run -p sq-01-anime-quote-cli -- character "Luffy"   # دیالوگ‌های مربوط به اون کاراکتر
```

فایل `src/main.rs` (اتصالات CLI — پارس کردن آرگومان‌ها، پرینت کردن) از قبل برات نوشته شده. کار تو نوشتن منطقِ لایبرری تو `src/lib.rs` هست: سرچ واقعی، فیلتر کردن و فرمت‌دهی که `main.rs` صداش می‌زنه. این دقیقا آینه‌ی یه الگوی واقعیه که مدام استفاده خواهی کرد: منطق اصلیت رو تو یه لایبرریِ قابل‌تست نگه دار، لایه‌ی فرانت‌اند/HTTP/خط‌فرمان رو سبک نگه دار.

## وظیفه‌ی تو

چهار تا تابع `!()todo` رو تو `src/lib.rs` پیاده‌سازی کن. تابع `()all_quotes` (خودِ دیتاست) از قبل ارائه شده — وقتی همه چی پاس شد، هر چقدر دلت خواست دیالوگ‌های محبوب خودت رو بهش اضافه کن، این کار هیچ تستی رو خراب نمی‌کنه.

## چک‌پوینت

اول `cargo test -p sq-01-anime-quote-cli` رو ران کن، بعد واقعاً هر چهار تا کامند بالا رو اجرا کن و خروجیش رو بخون. بعد برو سراغ `CHECKPOINT.md` و در نهایت `solution/SOLUTION.md`.
