# Side Quests

Themed, motivational mini-projects — the point where the fundamentals stop
feeling abstract. Each one only needs skills you've already unlocked by the
phase it's listed under; none of them block progress into the next phase,
but skipping them means skipping the most fun part of the repo.

| Side quest | Unlocked after | What it uses |
|---|---|---|
| [01 — Anime Quote CLI](sq-01-anime-quote-cli/README.md) | Phase 1 | structs/enums, pattern matching, `Vec`, `Option`/`Result` |
| [02 — Telegram Quiz Bot](sq-02-telegram-quiz-bot/README.md) | Phase 2 | async/`tokio`, `teloxide`, closures, error handling |
| [03 — Webtoon Notification Service](sq-03-webtoon-notifier-service/README.md) | Phase 3 | `axum`, `sqlx`/Postgres, scheduled polling, calls the Phase 2 bot |
| [04 — Anime/Manga Aggregator API](sq-04-anime-manga-aggregator-api/README.md) | Phase 4 | caching, rate limiting, observability |

These are also exactly the kind of small, finished, themed projects worth
linking from a portfolio/CV alongside the capstone — they show range (fun,
product-y work) next to TaskForge's depth (infra, market-relevant work).
