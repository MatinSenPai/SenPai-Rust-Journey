# مأموریت جانبی ۲ — ربات تلگرامی کوییز

اولین پروژه واقعیِ async تو — همه‌چیز از فاز ۲ (کلوژرها/ایتریتورها، مدیریت خطا، و به خصوص همروندی/async) به کار گرفته شده، بعلاوه اولین اتصال واقعیِ ربات با `teloxide`. همون روحیه تثبیتِ یادگیریِ مأموریت ۱ اینجا هم هست: هیچ *مفهوم* جدیدی در کار نیست، فقط به کار بستنِ مفاهیم اخیر روی یه چیز جذاب‌تر از تمرینات معمولی.

## چی کار می‌کنه

یه ربات تلگرام که ازت سوالاتِ اطلاعات عمومی انیمه/مانگا می‌پرسه، دونه‌دونه، و امتیازت رو تو طول یه نوبت پیگیری می‌کنه:

```
/quiz          شروع یک کوییز جدید
(reply 1-4)    پاسخ به سوال فعلی
/score         مشاهده امتیاز فعلی وسط کوییز
```

## ساختار (همون تفکیکِ `taskforge-admin-bot` و `taskforge-cli`)

- `src/lib.rs` — ساختار `QuizSession`، بانک سوالات، و تمام منطق امتیازدهی/وضعیت. صفر I/O، صفر وابستگی به `teloxide`، کاملاً یونیت‌تست‌شده.
- `src/main.rs` — اتصالات واقعی ربات `teloxide`: ذخیره‌سازی نوبت به ازای هر چت، هندل کردن کامندها، فرستادن پیام‌ها. برای اجرا نیاز به توکن واقعی ربات و اینترنت داره؛ با `cargo test` اجرا نمی‌شه.

## وظیفه‌ی تو

متدهای `QuizSession` رو تو `src/lib.rs` پیاده‌سازی کن (بانک سوالات ارائه شده). فایل `src/main.rs` کاملاً برات نوشته شده — وقتی کارت تموم شد بخونش تا ببینی چطوری مقدار کمی اتصالات `teloxide` ساختار `QuizSession` تست‌شده‌ت رو تبدیل به یه رباتِ واقعیِ در حال اجرا می‌کنه.

## چک‌پوینت

`cargo test -p sq-02-telegram-quiz-bot`. اگه می‌خوای واقعاً اجراش رو ببینی: یه توکن ربات از [@BotFather](https://t.me/BotFather) بگیر، بزن `...=export TELOXIDE_TOKEN` و بعد `cargo run -p sq-02-telegram-quiz-bot`. بعد برو سراغ `CHECKPOINT.md` و دست آخر `solution/SOLUTION.md`.
