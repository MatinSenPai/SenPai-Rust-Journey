# ایست بازرسی

۱. چرا `enum List { Cons(i32, List), Nil }` بدون `Box` با `error[E0072]: recursive type has infinite size` رد می‌شود؟ مرحله‌به‌مرحله توضیح بده چرا کامپایلر اندازه‌ی ثابتی پیدا نمی‌کند.

۲. `Box<List>` روی ماشین ۶۴ بیتی همیشه ۸ byte است. چرا اندازه‌ی خود `Box` به اندازه‌ی مقصدش وابسته نیست؟

۳. چرا `sum` امضای `pub fn sum(&self) -> i32` دارد و `self` را با value نمی‌گیرد؟ اگر مصرفش می‌کرد، فراخواننده پس از `.sum()` چه محدودیتی داشت؟

۴. داخل شاخه‌ی `Cons`، روی `rest: &Box<List>` مستقیم `rest.sum()` صدا می‌زنیم. کدام سازوکار این کار را بدون `(*rest).sum()` ممکن می‌کند؟

۵. غیر از نوع‌های بازگشتی، کجا از `Box<T>` استفاده می‌کنی؟ کاربرد مهم دیگر متن را نام ببر و توضیح بده چرا آن هم مشکل اندازه‌ی نامعلوم هنگام compile دارد.
