# چک‌پوینت

1. چرا دستور `} enum List { Cons(i32, List), Nil` (بدون استفاده از `Box`) اصلاً کامپایل نمی‌شه و خطای `error[E0072]: recursive type has infinite size` رو تولید می‌کنه؟ قدم به قدم و با زبون خودت توضیح بده که چرا کامپایلر نمی‌تونه یه سایز ثابت به این نوع (type) اختصاص بده.
2. تو یه سیستم ۶۴بیتی، یه `<Box<List>` همیشه ۸ بایته، فارغ از اینکه چند تا عنصر تو اون لیست وجود داره. چرا سایزِ `Box` اصلاً هیچ ربطی به سایزِ اون چیزی که داره بهش اشاره می‌کنه نداره؟
3. متد `sum` به این شکل تعریف شده: `pub fn sum(&self) -> i32`. چرا اینجا به جای `self` (گرفتن با ارزشِ خود مقدار یا by value)، داره `self&` رو می‌گیره؟ اگه به جای این کار می‌اومد و خود `self` رو مصرف می‌کرد (consumed)، چه تغییری تو اینکه فراخواننده‌ها (callers) بعد از صدا زدن `()sum.` بتونن دوباره با اون `List` کار کنن، به وجود می‌اومد؟
4. تو بازوی (arm) مربوط به `Cons` تو `match`، عبارتِ `()rest.sum` دقیقاً و مستقیماً روی نوعِ `<rest: &Box<List` صدا زده شده، بدون هیچ نیازی به استفاده از `()rest*.*` یا هیچ چیز دیگه‌ای شبیه به این. دقیقاً چه مکانیزمی باعث می‌شه این قضیه این‌طوری کار کنه؟
5. علاوه بر نوع‌های بازگشتی (recursive types)، کجای دیگه‌ای ممکنه خودت عمداً بری سراغ `<Box<T>`؟ (تو فایل README به یه مورد بزرگ دیگه‌اش اشاره شده بود — اسمش رو بگو و خیلی کوتاه توضیح بده که چرا اون مورد هم دقیقاً همون مشکلِ "سایزِ نامشخص تو زمان کامپایل" رو داره.)
