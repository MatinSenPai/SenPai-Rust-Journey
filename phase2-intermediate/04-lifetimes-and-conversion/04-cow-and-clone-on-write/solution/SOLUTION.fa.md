# راه‌حل — ۲.۴.۴ `Cow<'_, str>` و کپی‌هنگامِ‌نوشتن

```rust
pub fn describe(value: &Cow<'_, str>) -> &'static str {
    match value {
        Cow::Borrowed(_) => "borrowed",
        Cow::Owned(_) => "owned",
    }
}

pub fn collapse_spaces(input: &str) -> Cow<'_, str> {
    if !input.contains("  ") {
        return Cow::Borrowed(input);
    }
    let mut collapsed = String::with_capacity(input.len());
    let mut previous_was_space = false;
    for ch in input.chars() {
        if ch == ' ' && previous_was_space {
            continue;
        }
        previous_was_space = ch == ' ';
        collapsed.push(ch);
    }
    Cow::Owned(collapsed)
}

pub fn ensure_exclaimed(mut value: Cow<'_, str>) -> Cow<'_, str> {
    if !value.ends_with('!') {
        value.to_mut().push('!');
    }
    value
}
```

## `describe` — یک `match` معمولی، چون هیچ راهِ دیگری نیست

`Cow`، همان‌طور که درس گفت، یک شمارشیِ واقعی است — و تنها راهِ فهمیدنِ اینکه کدام گونه‌اش را داری، یا `match` است یا چیزی که خودش رویِ `match` بنا شده (مثلِ همین ماکروی `matches!` که تویِ خودِ تست‌ها زیاد دیدی). این تابع دقیقاً کاری می‌کند که یک `{:?}` نمی‌تواند: `Debug`، همان‌طور که در «مفهوم» دیدی، مستقیم به مقدارِ داخلی عبور می‌کند، نه به اسمِ گونه. برایِ همین امضا عمداً `&Cow<'_, str>` می‌گیرد نه `&str` — یک `&str` این اطلاعات را از قبل پاک کرده بود.

## `collapse_spaces` — یک بررسیِ ارزان قبل از هر تصمیمی

```rust
if !input.contains("  ") {
    return Cow::Borrowed(input);
}
```

این خط کلِ تابع را در دو دسته جدا می‌کند، قبل از اینکه حتی یک بایت تخصیص بگیرد. `.contains("  ")` خودش رویِ ورودی فقط می‌خواند — هیچ کپی‌ای در کار نیست — و اگر جوابش منفی باشد، `input` همان لحظه، بدونِ هیچ تغییری، برمی‌گردد. این دقیقاً همان اثباتِ آدرس‌محوری است که در بخشِ «شکلِ انگیزه‌ساز» دیدی.

```rust
let mut previous_was_space = false;
for ch in input.chars() {
    if ch == ' ' && previous_was_space {
        continue;
    }
    previous_was_space = ch == ' ';
    collapsed.push(ch);
}
```

وقتی واقعاً یک اجرا پیدا شود، حلقه با یک پرچم ساده کار را انجام می‌دهد: هر کاراکتر، جز فاصله‌ای که بلافاصله بعدِ یک فاصله‌ی دیگر آمده، به `collapsed` اضافه می‌شود. `previous_was_space` را دقیقاً همان‌جایی به‌روزرسانی می‌کنیم که کاراکتر واقعاً پوش شده — یعنی برایِ کاراکترهایی که `continue` می‌شوند (یعنی خودِ فاصله‌های اضافه) دست‌نخورده می‌ماند، که دقیقاً همان چیزی است که باعث می‌شود یک اجرایِ سه‌فاصله‌ای به یک فاصله‌ی تنها جمع شود، نه صفر فاصله. تب‌ها و خط‌های تازه هیچ‌وقت با `' '` برابر نیستند، پس شرط برایشان همیشه نادرست است و همیشه دست‌نخورده رد می‌شوند.

## `ensure_exclaimed` — چک کن، بعد `to_mut()` بزن، نه برعکس

```rust
if !value.ends_with('!') {
    value.to_mut().push('!');
}
value
```

ترتیب اینجا مهم است. `.ends_with('!')` رویِ `Cow` از پشتِ `Deref` کار می‌کند — بدونِ اینکه به `.to_mut()` نیازی باشد، پس اگر `value` از قبل به `'!'` ختم شده باشد، تابع اصلاً هیچ‌وقت `.to_mut()` را صدا نمی‌زند و `value` — چه `Borrowed` بود چه `Owned` — دقیقاً همان‌طوری که رسیده برمی‌گردد. فقط وقتی واقعاً چیزی برایِ اضافه‌کردن هست، `.to_mut()` صدا زده می‌شود: اگر `value` هنوز `Borrowed` بود، همین یک صدا زدن آن را کلون می‌کند؛ اگر از قبل `Owned` بود، هیچ کلونِ تازه‌ای در کار نیست. این دقیقاً همان چیزی است که «کپی‌هنگامِ‌نوشتن» را واقعی می‌کند، نه فقط یک اسم.

## این درس واقعاً درباره‌ی چه بود

- **`Cow` یک enum واقعی است که `Deref` باعث می‌شود کمتر مجبور باشی رویش دست بگذاری.** `describe` تنها جایی در این درس بود که واقعاً به یک `match` صریح نیاز داشت — همه‌جایِ دیگر، `Deref` کار را کرد.
- **تصمیمِ Borrowed-در-برابرِ-Owned همیشه با یک بررسیِ ارزان می‌آید، قبل از هر تخصیصی.** `collapse_spaces` این را با `.contains("  ")` نشان داد؛ الگو همیشه همین شکل است: اول بپرس، بعد بساز.
- **`.to_mut()` فقط وقتی صدا زده می‌شود که واقعاً لازم است، نه هر بار.** `ensure_exclaimed` این را با گذاشتنِ `.ends_with('!')` جلوترِ `.to_mut()` نشان داد — دقیقاً همان انضباطی که کلونِ بی‌مورد را کنار می‌گذارد.
