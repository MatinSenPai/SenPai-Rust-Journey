# راه‌حل — ۲.۴.۲ طول‌عمر در ساختارها و متدها

## `whole`

```rust
pub fn whole(source: &'a str) -> Self {
    Excerpt { text: source }
}
```

بدونِ هیچ پردازشی، `source` مستقیم می‌شود `text`. امضا از قبل نوشته شده بود: `source: &'a str` صریح، چون این یک تابعِ وابسته است نه یک متد — هیچ `&self`ای در کار نیست که قانونِ سوم بخواهد رویش کار کند.

## `text`

```rust
pub fn text(&self) -> &str {
    self.text
}
```

هیچ `'a` نه رویِ امضا، نه هیچ‌جایِ دیگر. قانونِ سومِ حذف — همان‌طور که «مفهوم» توضیح داد — طول‌عمرِ خروجیِ حذف‌شده را به همان قرضِ `&self` می‌دهد، و چون `self.text` (که `&'a str` است) همیشه دستِ‌کم به‌اندازه‌ی خودِ آن قرض عمر می‌کند، کوتاه‌کردنش امن است.

## `word_count`

```rust
pub fn word_count(&self) -> usize {
    self.text.split_whitespace().count()
}
```

`.split_whitespace()` دقیقاً همان چیزی است که کامنتِ مستندات خواسته بود: تکه‌تکه‌کردن رویِ فضایِ‌خالی، بدونِ اینکه رشته‌هایِ خالیِ اضافه بسازد وقتی چند فاصله پشتِ سرِ هم می‌آید. `.count()` تعدادِ تکه‌ها را می‌دهد.

## `total_words`

```rust
pub fn total_words(excerpts: &[Excerpt<'_>]) -> usize {
    excerpts.iter().map(Excerpt::word_count).sum()
}
```

یک پیمایشِ ساده: هر `Excerpt` را به `word_count()`ش نگاشت بده، بعد جمعشان بزن. طول‌عمرِ برشِ ورودی همان‌جا با `'_` حذف شده — این تابع فقط داده‌ی داخلِ هر `Excerpt` را می‌خواند، هیچ ارجاعی از آن‌ها بیرون نمی‌برد، پس چیزی برایِ اسم‌بردنِ صریح نیست.
