# راه‌حل

```rust
pub fn shorter<'a>(a: &'a str, b: &'a str) -> &'a str {
    if a.len() <= b.len() {
        a
    } else {
        b
    }
}
```

`shorter<'a>(a: &'a str, b: &'a str) -> &'a str` همان `longest` است، فقط با مقایسه‌ای برعکس و همان قاعده‌ی تساوی: وقتی `a.len() <= b.len()` باشد، `a` برنده می‌شود — پس یک تساویِ دقیق هم `a` را برمی‌گرداند. `<'a>` روی هر دو پارامتر و روی خروجی دقیقاً به همان دلیلی لازم است که در `longest` لازم بود — دو ارجاعِ ورودی، و خروجی می‌تواند از نظرِ نوع از هرکدام‌شان بیاید، پس هیچ‌کدام از سه قاعده‌ی حذف نمی‌تواند خودش تصمیم بگیرد.

```rust
pub fn first_sentence(text: &str) -> &str {
    match text.split_once('.') {
        Some((before, _after)) => before,
        None => text,
    }
}
```

`first_sentence(text: &str) -> &str` اصلاً به هیچ `<'a>`ی نیاز نداشت — قاعده‌ی حذفِ ۲ فعال می‌شود، چون دقیقاً یک ارجاعِ ورودی هست. `.split_once('.')` اینجا ابزارِ تمیزتری است نسبت به `.split('.').next()`: وقتی جداکننده واقعاً نباشد، `None` برمی‌گرداند، پس بازوی `None` بالا واقعاً قابلِ‌دسترسی است و واقعاً یعنی «هیچ نقطه‌ای پیدا نشد» — چیزی بی‌خبر دست‌نیافتنی نمانده.

```rust
impl Setting {
    pub fn value(&self) -> &str {
        match self.raw.split_once('=') {
            Some((_key, value)) => value,
            None => &self.raw,
        }
    }
}
```

`value(&self) -> &str` قاعده‌ی حذفِ ۳ است: `&self` تنها ارجاعِ داخلِ امضاست، پس طول‌عمرش خودکار به خروجی داده می‌شود — هیچ `<'a>`ی روی این متد نیست، با اینکه خودِ `Setting` یک ساختارِ کاملاً معمولی است، بدونِ هیچ پارامترِ طول‌عمری. همین نکته‌ی آخر مهم است: `Setting` یک `String` را کاملاً مالکانه نگه می‌دارد، پس این متد دقیقاً همان شکلی است که [۲.۴.۲](../../02-lifetimes-in-structs-and-methods/README.fa.md) در برابرِ ساختاری که یک فیلدِ *قرضی* نگه می‌دارد قرارش می‌دهد.

**درباره‌ی سؤالِ ۵ گرم‌کردن:** امضایِ `fn longest<'a>(x: &'a str, y: &str) -> &'a str` با بدنه‌ای که در درس دیدی **کامپایل نمی‌شود**. فقط `x` به `'a` گره خورده؛ `y` طول‌عمرِ کاملاً مستقل و بی‌نامِ خودش را می‌گیرد. همان لحظه‌ای که شاخه‌ی `else`ِ بدنه می‌خواهد `y` را با نوعِ `&'a str` برگرداند، کامپایلر هیچ اثباتی ندارد که طول‌عمرِ واقعیِ `y` واقعاً `'a` را پوشش می‌دهد — پس رد می‌کند، با `E0621`، حتی پیش از اینکه به هیچ محلِ فراخوانیِ واقعی برسد. گره‌زدنِ هر دو ورودی به همان `'a` دقیقاً همان اثبات را فراهم می‌کند؛ هیچ‌کدام از ورودی‌ها را بیشتر از آنچه هستند زنده نگه نمی‌دارد.
