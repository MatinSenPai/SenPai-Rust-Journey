# ۰۸ — جعبه‌ابزار Rust

تا اینجا دیگه می‌تونی کدهای واقعی و به درد بخور تو زبان Rust بنویسی: با ساختارهای داده (collections)، پیمایشگرها (iterators)، خصیصه‌ها (traits)، نوع‌های خطا، اشاره‌گرهای هوشمند و async کار کردی. این ماژول مثل یه کشو از ابزارهای مختلفه — چهار تا مبحث نسبتاً کوچیکتر که هر کدومشون اونقدری بزرگ نبودن که یه ماژولِ کامل و جداگانه رو به خودشون اختصاص بدن، اما تو فاز ۳ به بعد قرار به طور مداوم و پشت‌سرهم سراغشون بری و تو کریت‌هایی که بقیه می‌نویسن، تو تک‌تک صفحه‌هاشون اینا رو می‌بینی: ویژگی‌های مربوط به pattern-matching (تطبیق الگو) که تو درس‌های اول ازشون گذشتیم، اولین ماکرویِ `!macro_rules` خودت (همراه با یه راهنمایی صادقانه درباره‌ی اینکه کی *نباید* یکی از اونا بنویسی)، استفاده از ویژگی‌های Cargo (یعنی Cargo features) برای پیکربندی تو زمان کامپایل، و در نهایت `TryFrom` برای تبدیل‌هایی که ممکنه با خطا مواجه بشن. برای کسی که از پایتون میاد: این ماژول تقریباً معادل پرش از مرحله‌ی «من می‌تونم یه view ساده تو جنگو بنویسم» به مرحله‌ی «من `args*`، دکوراتورها، `[pip install package[extra` و اینکه چرا `(int(x` ممکنه خطای `ValueError` بده رو کامل می‌فهمم» هست — همون الگوهایی (idioms) که تو رو از یه برنامه‌نویسِ صرفاً کارراه‌انداز، به یه برنامه‌نویسِ مسلط و روون تبدیل می‌کنن. تک‌تک درس‌های این ماژول عمداً کوتاه و مستقل طراحی شدن؛ مسیر ۱ تا ۴ مسیر طبیعیِ خوندنشونه، اما درس‌های بعدی هیچ وابستگی و نیازی به درس‌های قبلی ندارن.
