# ایست بازرسی

۱. matcher و transcriber چه تفاوتی دارند و expansion چه زمانی رخ می‌دهد؟
۲. چرا syntax به‌شکل `"k" => "v"` را function معمولی نمی‌تواند بپذیرد؟
۳. expansion مربوط به `max_of!(3, 9, 7)` را مرحله‌به‌مرحله بنویس و نقش base case را بگو.
۴. تست ارزیابی دقیقاً یک‌بار، کدام transcriber اشتباه را می‌گیرد و چرا `let result = $work;` اصلاحش می‌کند؟
۵. identifier داخلی `start` با متغیر هم‌نام caller چه می‌کند و نام این خاصیت چیست؟
۶. برای ماکرویی که early return پنهان دارد دو دلیل review برای ترجیح function بنویس.
