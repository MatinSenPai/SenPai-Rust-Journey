# راه‌حل

`wrap` و `unwrap_box` دو جهتِ یک حرکتِ واحدند — رفتن رویِ هیپ، بعد برگشتن ازش:

```rust
pub fn wrap(value: i32) -> Box<i32> {
    Box::new(value)
}

pub fn unwrap_box(boxed: Box<String>) -> String {
    *boxed
}
```

`*boxed` اینجا خواندن از پشتِ یک قرض نیست — `unwrap_box` مالکِ کاملِ `boxed` است، پس `*boxed` همان `String` را از دلِ تخصیصِ هیپ بیرون می‌کشد و پسش می‌دهد، و خودِ جعبه هم در همین کار مصرف می‌شود. این دقیقاً همان حرکتی است که مثالِ `E0507` در متنِ درس نشانت داد از پشتِ یک ارجاعِ اشتراکی *نمی‌شود* انجامش داد — مالکیتِ واقعیِ `Box` دقیقاً همان چیزی است که این کار را مجاز می‌کند.

`increment_boxed` به دو بار بازکردنِ ارجاع نیاز دارد، نه یکی:

```rust
pub fn increment_boxed(boxed: &mut Box<i32>) -> i32 {
    **boxed += 1;
    **boxed
}
```

`boxed` نوعش `&mut Box<i32>` است — یک ارجاعِ تغییرپذیر به خودِ جعبه، نه مستقیم به `i32`. اولین `*` همان ارجاع را دنبال می‌کند تا به خودِ `Box<i32>` برسد؛ دومی `Box` را دنبال می‌کند تا به `i32`ای برسد که مالکش است. یکی را جا بیندازی، یا داری چیزِ اشتباهی را زیاد می‌کنی یا اصلاً نوع‌ها جور در نمی‌آیند.

اندازه‌گیری، قلبِ این درس است، و کوتاه‌ترین تابعِ این فایل هم همین است:

```rust
pub fn box_size_report() -> (usize, usize, usize) {
    (
        size_of::<Box<i32>>(),
        size_of::<Box<[u8; 4096]>>(),
        size_of::<Box<Box<i32>>>(),
    )
}
```

سه‌تا `T` که زمین تا آسمون با هم فرق دارند — چهار بایت، چهار هزار و نود و شش بایت، و یک `Box`ِ دیگر — و سه جوابِ یکسان. هیچ جایی از کد لازم نیست شاخه بزند یا برایِ هرکدام حالتِ جدا بنویسد؛ اندازه‌ی `Box<T>`، وقتی `T` اندازه‌دار باشد، اصلاً اندازه‌ی `T` را نمی‌خواند.

`make_playable_list` ساختِ معمولیِ شیءِ صفتی است، دقیقاً همان شکلی که [۲.۳.۷](../../../03-traits-and-generics/07-static-vs-dynamic-dispatch/README.fa.md) از قبل یادت داده بود — کارِ این درس فقط این بود که بگوید چرا `Box<dyn Playable>` می‌تواند یک `Song` و یک `Podcast` را کنارِ هم نگه دارد:

```rust
pub fn make_playable_list() -> Vec<Box<dyn Playable>> {
    vec![
        Box::new(Song {
            title: "Intro".to_string(),
        }),
        Box::new(Podcast {
            title: "Deep Dive".to_string(),
            duration_minutes: 42,
        }),
    ]
}
```

`Song` و `Podcast` رویِ پشته اندازه‌های متفاوتی دارند، ولی هر عنصرِ این `Vec` همان یک `Box<dyn Playable>` است — یک اشاره‌گرِ چاق، شانزده بایت، فارغ از اینکه سرِ دیگرش کدام ساختار نشسته.
