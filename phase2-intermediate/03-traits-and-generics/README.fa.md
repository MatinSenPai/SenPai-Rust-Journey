# ۰۳ — صفت‌ها و جنریک‌ها

صفت‌ها (traits) راهِ Rust برای چندریختی بدونِ ارث‌بری‌اند، و جنریک‌ها راهِ انجامِ
همین کار بدونِ هزینه‌ی آن در زمانِ اجرا. این ماژول جایی است که «جنریک» دیگر
معنیِ «مبهم» نمی‌دهد و معنیِ «یک‌بار نوشته‌شده، برای هر نوعی که واجدِ شرایط
است کار می‌کند» می‌گیرد — و همه‌اش هنگامِ کامپایل بررسی می‌شود.
