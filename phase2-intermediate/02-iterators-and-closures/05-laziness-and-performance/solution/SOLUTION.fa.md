# راه‌حل — ۲.۲.۵ تنبلی و کاراییِ ایتریتورها

```rust
pub fn powers_of_two(n: usize) -> Vec<u64> {
    std::iter::successors(Some(1u64), |&x| Some(x * 2))
        .take(n)
        .collect()
}

pub fn cycle_to_length(pattern: &[i32], total_len: usize) -> Vec<i32> {
    pattern.iter().copied().cycle().take(total_len).collect()
}

pub fn first_n_multiples_of(k: u32, n: usize) -> Vec<u32> {
    (1..).map(|i| i * k).take(n).collect()
}

pub fn multiples_of_k_below(k: u32, limit: u32) -> Vec<u32> {
    if k == 0 {
        return Vec::new();
    }
    (1..).map(|i| i * k).take_while(|&m| m < limit).collect()
}

pub fn first_n_even_with_scan_count(numbers: &[i32], n: usize) -> (Vec<i32>, usize) {
    let mut found = Vec::new();
    let mut scanned = 0;
    for &value in numbers {
        if found.len() >= n {
            break;
        }
        scanned += 1;
        if value % 2 == 0 {
            found.push(value);
        }
    }
    (found, scanned)
}
```

هیچ‌کدام از این پنج تابع به یک `struct` سفارشی یا یک حلقه‌ی پیچیده نیاز نداشت — سه‌تایشان فقط همان ابزارهایی‌اند که در «مفهوم» دیدی، این‌بار روی ورودیِ خودشان؛ چهارمی یک لبه‌ی کوچک داشت که باید هشیارش می‌بودی؛ پنجمی حتی از همین درس هم چیزِ تازه‌ای قرض نگرفت.

## `powers_of_two` — `successors`، بدونِ هیچ `struct` سفارشی

```rust
std::iter::successors(Some(1u64), |&x| Some(x * 2))
    .take(n)
    .collect()
```

`successors` دقیقاً همان مولدی است که در «پاداشِ مستقیم» دیدی — با `1` شروع می‌کند، هر بار مقدارِ قبلی را دوبرابر می‌کند، و چون هیچ‌وقت `None` برنمی‌گرداند، تنها چیزی که جلویش را می‌گیرد `.take(n)` است. برایِ `n = 0`، `.take(0)` حتی یک‌بار هم کلوژر را صدا نمی‌زند — نتیجه `vec![]` می‌شود، دقیقاً همان‌طور که مشخصات خواسته بود.

## `cycle_to_length` — `.cycle()` با یک ترفندِ رایگان برایِ ورودیِ خالی

```rust
pattern.iter().copied().cycle().take(total_len).collect()
```

هیچ چکِ جداگانه‌ای برایِ `pattern.is_empty()` لازم نبود — کتابخانه‌ی استاندارد همین رفتار را مجانی می‌دهد: `.cycle()` رویِ یک منبعِ خالی، خودش خالی می‌ماند، نه گیر می‌کند و نه پنیک می‌گیرد. `.copied()` هم فقط `&i32`هایِ `.iter()` را به `i32` تبدیل می‌کند، همان چیزی که امضایِ تابع می‌خواست.

## `first_n_multiples_of` — همان بازه‌ی بازِ `1..` که در «مفهوم» دیدی

```rust
(1..).map(|i| i * k).take(n).collect()
```

همان الگویِ `(1..).map(...).take(n)`ای که برایِ اثباتِ تنبلی به‌کار بردیم، این‌بار فقط برایِ تولیدِ یک دنباله. چون `k` هیچ‌وقت `0` نیست — مشخصات همین را تضمین کرده — هیچ خطرِ حلقه‌ی بی‌پایانی در کار نیست.

## `multiples_of_k_below` — چرا `k == 0` باید قبل از هر چیز چک شود

```rust
if k == 0 {
    return Vec::new();
}
(1..).map(|i| i * k).take_while(|&m| m < limit).collect()
```

این‌جا دقیقاً همان خطری است که این درس درباره‌اش هشدار داد. اگر `k` صفر باشد، هر مضربی هم صفر است، و `0 < limit` برایِ هر `limit`ِ مثبتی همیشه درست می‌ماند — `.take_while()` هیچ‌وقت شرطش را نقض‌شده نمی‌بیند، و بدونِ آن `if`، این تابع دقیقاً همان ایتریتورِ بی‌نهایتِ ناخواسته‌ای می‌شد که «خطاهایی که خواهی دید» درباره‌اش صحبت کرد. آن `if k == 0` سه‌خطی، دقیقاً همان چیزی است که جلویش را می‌گیرد.

## `first_n_even_with_scan_count` — یک حلقه‌ی ساده، نه یک زنجیره

```rust
let mut found = Vec::new();
let mut scanned = 0;
for &value in numbers {
    if found.len() >= n {
        break;
    }
    scanned += 1;
    if value % 2 == 0 {
        found.push(value);
    }
}
(found, scanned)
```

این یکی عمداً یک حلقه‌ی دستی است، نه یک زنجیره‌ی آداپتور — دقیقاً همان استدلالِ «همان مقدار کار، فقط با اسمی دیگر» از «مفهوم». `scanned` فقط وقتی بالا می‌رود که واقعاً یک عنصر بررسی شده باشد؛ چکِ `found.len() >= n` قبل از آن است، پس برایِ `n = 0` حلقه حتی یک عنصر هم نمی‌بیند و `scanned` صفر می‌ماند — دقیقاً همان چیزی که مشخصات قول داده بود.

## این درس واقعاً درباره‌ی چه بود

- **هیچ‌کدام از این پنج تابع به جنریک، `Box` یا هیچ نوعِ برگشتیِ `impl Trait` نیاز نداشت** — همه رویِ نوع‌های ملموسی کار کردند که از قبل می‌شناسی.
- **`(1..)` و `successors` هر دو یک منبعِ بی‌نهایت‌اند؛ فرقشان فقط در این است که مقدارِ بعدی از کجا می‌آید** — یکی از یک شمارنده، دیگری از خودِ مقدارِ قبلی.
- **`multiples_of_k_below` تنها جایی بود که واقعاً باید هشیار می‌بودی** — بدونِ چکِ `k == 0`، همان چیزی که این درس هشدارش را داد، همین‌جا واقعاً اتفاق می‌افتاد.
- **`first_n_even_with_scan_count` یادآوری بود که «تنبلی» یک ایده است، نه فقط یک ابزار** — حتی بدونِ هیچ آداپتوری، همان منطقِ «فقط به‌اندازه‌ی لازم نگاه کن» را با یک حلقه‌ی ساده هم می‌شود نوشت.
