# راه‌حل — ۰۳ سلام Rust

```rust
pub fn describe_journey(language: &str, day: u32) -> String {
    format!("Day {day} of learning {language}: still compiling.")
}

pub fn shout(line: &str) -> String {
    format!("{}!", line.to_uppercase())
}

pub fn progress_bar(done: usize, total: usize) -> String {
    format!(
        "[{}{}] {done}/{total}",
        "#".repeat(done),
        ".".repeat(total - done)
    )
}
```

## `describe_journey`

یک `format!`، بدونِ `return`، بدونِ سمی‌کالن روی خطِ آخر. اگر مالِ تو `return` دارد، کار می‌کند — ولی در درسِ ۰۶ خودِ `cargo clippy` می‌گوید برش دار، پس همین حالا عادتش را بگذار.

به دو سبکِ درهم‌آمیخته در یک رشته دقت کن: `{day}` و `{language}` مستقیم اسمِ متغیر را می‌گیرند، در حالی که `{}` در بقیه به‌ترتیب پر می‌شود. می‌شود آزادانه ترکیبشان کرد. هر وقت مقدار از قبل در یک متغیر است، شکلِ نام‌دار بهتر است.

## `shout` — چرا `{}` و نه `{line}`

```rust
format!("{}!", line.to_uppercase())
```

نمی‌توانی بنویسی `format!("{line.to_uppercase()}!")`. شکلِ `{name}` یک **اسمِ متغیر** می‌گیرد، نه یک عبارت. اگر فراخوانیِ متد می‌خواهی، یا از `{}`ِ موقعیتی استفاده کن و عبارت را به‌عنوانِ آرگومان بده، یا اول بایندش کن:

```rust
let shouted = line.to_uppercase();
format!("{shouted}!")
```

هر دو درست‌اند. اولی کوتاه‌تر است؛ دومی وقتی عبارت طولانی است خواناتر.

`to_uppercase` یک `String` تازه برمی‌گرداند و `line` را تغییر نمی‌دهد — و اصلاً نمی‌تواند تغییرش بدهد، چون `line` یک `&str` است: متنی قرض‌گرفته که مالکش نیستی. این همان سیستمِ مالکیت است که دارد از لایِ کد پیدا می‌شود، و فاز ۱ صریحش می‌کند.

## `progress_bar` — `repeat` بهتر از حلقه است

```rust
"#".repeat(done)
```

شاید به‌جایش حلقه نوشته باشی. کار می‌کند، ولی `repeat` در یک فراخوانی می‌گوید چه‌کار می‌کند، و یک بار حافظه می‌گیرد به‌جای اینکه رشته را مدام بزرگ کند.

بخشی که ارزشِ فکر کردن دارد، همان تفریق است:

```rust
".".repeat(total - done)
```

اگر `done` هیچ‌وقت از `total` بزرگ‌تر می‌شد، `total - done` زیرریز می‌کرد — و روی `usize` این در حالتِ debug پنیک می‌کند و در حالتِ release به یک عددِ عظیم می‌پیچد. داکِ تابع گفته `done` هیچ‌وقت از `total` بزرگ‌تر نیست، پس **با فرضِ همان قرارداد** درست است.

این یک الگوی واقعی است که ارزشِ دیدن دارد: **یک کامنتِ داک که یک پیش‌شرط را اعلام می‌کند، دارد بارِ واقعی حمل می‌کند.** در فاز ۱ یاد می‌گیری چطور به‌جای اعتماد به کامنت، خودِ سیستمِ نوع را وادار کنی این را تضمین کند.

## این تمرین‌ها واقعاً چه چیزی را می‌سنجیدند

نه `format!` را. می‌سنجیدند که آیا این سه تا برایت درونی شده:

۱. آخرین عبارت، مقدارِ بازگشتی است.
۲. `&str` بگیر، `String` بده.
۳. کجا `{name}` کار می‌کند و کجا به `{}` نیاز داری.

اگر هر سه الان خودکار شده‌اند، این درس کارش را کرده.
