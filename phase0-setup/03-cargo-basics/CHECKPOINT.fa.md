# ایست بازرسی — Cargo

1. فرق `cargo check` و `cargo build` چیست و هرکدام را چه زمانی انتخاب می‌کنی؟
2. کد منبع مربوط به crate `rand` کجا cache می‌شود و `Cargo.lock` چه چیزی را ثبت می‌کند؟
3. `edition.workspace = true` مقدار واقعی را از کجا می‌گیرد؟
4. `cargo test` چگونه تابع‌های دارای `#[test]` را پیدا می‌کند؟
5. `cargo run -- YourName 3` و سپس `cargo run -- YourName abc` را اجرا کن. علت رفتار دوم را در parsing مقدار `times` پیدا کن.
