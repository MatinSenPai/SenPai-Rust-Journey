# چک‌پوینت — مبانی Cargo

1. تفاوت بین `cargo check` و `cargo build` چیه؟ کی از هر کدومشون استفاده می‌کنی؟
2. کد اصلی crate `rand` دقیقاً کجا دانلود می‌شه؟ (راهنمایی: دنبال یه پوشه‌ی جدید بگرد که `cargo` بیرون از پوشه‌ی این درس می‌سازه، و بعد از یه دور `build` کردن، فایل `Cargo.lock` تو ریشه‌ی workspace رو نگاه کن.)
3. عبارت `edition.workspace = true` تو فایل `Cargo.toml` این درس به چه معناست و مقدار واقعی که در نهایت بهش می‌رسه کجا تعریف شده؟
4. دستور `cargo test` سه تا تست رو تو فایل `src/lib.rs` اجرا کرد اما تو هیچ‌وقت تو قسمت `mod tests` از `cargo run` استفاده نکردی. `cargo test` چطور متوجه می‌شه که اونا رو پیدا و اجرا کنه؟
5. دستور `cargo run -- YourName 3` و بعدش `cargo run -- YourName abc` رو امتحان کن — تو حالت دوم چه اتفاقی می‌افته و با توجه به نحوه‌ی پارس شدن `times` تو فایل `main.rs`، چرا این اتفاق می‌افته؟
