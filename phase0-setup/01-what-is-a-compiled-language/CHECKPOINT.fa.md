# ایست بازرسی — زبان کامپایل‌شده

1. `rustc` چه خروجی‌ای تولید می‌کند و این خروجی با اجرای فایل `.py` توسط `python3` چه تفاوتی دارد؟
2. اگر خطای نوع در خط ۴۰۰ فقط پشت یک گزینه‌ی نادر باشد، Rust چه زمانی آن را می‌بیند؟ پاسخ برای خطای مشابه Python چیست؟ آیا کامپایلر هر خطای منطقی را هم می‌گیرد؟
3. آیا فایل اجرایی کامپایل‌شده روی Linux با معماری و وابستگی‌های سازگار، بدون نصب Rust اجرا می‌شود؟ فایل `.py` بدون Python چطور؟
4. اصطکاک بیشتر را پیش از اجرا می‌بینی یا هنگام اجرا؟ این معامله برای بک‌اند چه سودی دارد؟
