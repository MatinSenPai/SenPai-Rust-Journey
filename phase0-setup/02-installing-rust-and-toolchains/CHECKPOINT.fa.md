# چک‌پوینت — نصب Rust و toolchainها

1. ابزار `rustup` چه چیزی رو مدیریت می‌کنه که خود `rustc` به‌تنهایی انجامش نمی‌ده؟ نزدیک‌ترین ابزاری که تو دنیای پایتون می‌شناسی رو اسم ببر.
2. فایل `rust-toolchain.toml` تو این مخزن چه چیزی رو تضمین می‌کنه و چرا این قضیه برای پروژه‌ای که ممکنه بعد از ماه‌ها سراغش بیای مفیده؟
3. «ویرایش‌ها» (editions) تو Rust چه مشکلی رو حل می‌کنن و این چه فرقی با نحوه‌ی برخورد با انتقال پایتون ۲ به ۳ داره؟
4. همین الان `rustc --version` و `cargo --version` رو اجرا کن و خروجی‌شون رو یه جایی که جلوی چشمت باشه پیست کن (یه یادداشت موقت هم کافیه) — چه نسخه‌ای رو گرفتی و آیا با نسخه‌ی "stable" امروز مطابقت داره؟
