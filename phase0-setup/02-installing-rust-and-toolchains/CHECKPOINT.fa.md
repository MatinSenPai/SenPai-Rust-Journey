# ایست بازرسی — نصب Rust

1. `rustup` چه چیزی را مدیریت می‌کند که `rustc` به‌تنهایی مدیریت نمی‌کند؟ معادل نزدیک آن در Python چیست؟
2. `rust-toolchain.toml` چه تضمینی می‌دهد و چرا برای بازگشت به پروژه پس از چند ماه مفید است؟
3. editionهای Rust چه مسئله‌ای را حل می‌کنند و چه تفاوتی با Python 2 → 3 دارند؟
4. `rustc --version` و `cargo --version` را اجرا و خروجی واقعی را ثبت کن. آیا channel پروژه stable است؟
