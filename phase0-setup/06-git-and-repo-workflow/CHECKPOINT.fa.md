# چک‌پوینت — گردش کار Git و مخزن

1. این مخزن به کدوم سه تا فایل/مکان وابسته است که به کمک اون‌ها می‌تونی (تو یا هر کس دیگه‌ای) بدون پرسیدن از کسی متوجه بشی که «الان کجای مسیرم»؟
2. پیام دقیق commitای رو که بعد از اتمام درس `phase1-fundamentals/01-variables-types-control-flow/01-variables-mutability-shadowing` استفاده می‌کنی بنویس (فعلاً اجراش نکن).
3. چرا تو قراردادها گفته شده که تیک درس تو `PROGRESS.md` رو تو *همون* commitای بزنی که درس رو تموم می‌کنی، به جای اینکه چند تا تیک رو با هم نگه داری و تو یه commit جداگانه بعداً آپدیتشون کنی؟
4. اون کامنت (comment) تو فایل `Cargo.toml` ریشه پروژه که توضیح داده کدوم درس‌ها از قصد تو لیست `members` قرار نگرفتن رو پیدا کن. چرا اضافه کردن اون‌ها دستور `cargo build --workspace` رو خراب می‌کنه؟
