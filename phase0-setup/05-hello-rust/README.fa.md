# ۰۵ — سلام، Rust

اولین برنامه‌ی واقعی تو. این برنامه عمداً کوچیک در نظر گرفته شده — هدف اینه که چرخه‌ی `cargo new` ← ویرایش فایل ← `cargo run` رو قبل از شروع فاز یک (که حسابی وارد بحث سینتکس می‌شیم)، از اول تا آخرش یه بار با هم ببینیم.

## تابع `fn main`

هر crate از نوع **binary** تو Rust، دقیقاً به یک `fn main() { ... }` نیاز داره — این همون نقطه‌ی ورود (entry point) برنامه‌ست، نقشش دقیقاً مثل `if __name__ == "__main__":` تو پایتونه، با این تفاوت که اینجا اجباریه و هیچ ابهامی هم نداره: اینجا معادلی برای «این فایل ممکنه به جای اجرا شدن، وارد (import) بشه» وجود نداره.

## `!println` یک ماکروئه، نه یک تابع

به اون علامت `!` دقت کن. `println!("Hello, {name}!")` یه **ماکرو (macro)** به حساب میاد — تو زمان کامپایل اجرا می‌شه و تبدیل به همون کدهای واقعیِ مربوط به چاپ کردن می‌شه. به همین خاطره که می‌تونه کاری رو بکنه که یه تابع معمولی نمی‌تونه: رشته‌ی فرمت‌شده‌ات رو *تو همون زمان کامپایل* با آرگومان‌هایی که دادی چک می‌کنه و اگه با هم همخونی نداشته باشن، کلاً اجازه نمیده برنامه کامپایل بشه (یه بار `println!("{name}")` رو بدون اینکه متغیری به اسم `name` داشته باشی امتحان کن — خطای کامپایلر رو همون موقع و قبل از اینکه اصلاً چیزی رو اجرا کنی می‌بینی). خیلی جلوتر (بخش‌های تقویتی فاز ۲) ماکروهای ساده‌ی خودت رو می‌نویسی؛ فعلاً فقط بدون که هر وقت این علامت `!` رو دیدی (مثل `println!`، `vec!`، `format!`، `todo!` — این آخری رو که تا همینجاش هم تو تمام درس‌ها استفاده کردی) معنیش اینه که «این یه ماکروئه».

## وظیفه‌ی تو

فایل `src/lib.rs` یه تابع برای پیاده‌سازی داره: `describe_journey`. فایل `src/main.rs` همین الانم داره اون رو صدا می‌زنه — تو همون `main.rs` چیزی رو ویرایش نکن، فقط برو همون تابع رو تو library درستش کن.

```sh
cargo test -p p0-05-hello-rust
cargo run -p p0-05-hello-rust
```
