# چک‌پوینت — سلام، Rust

1. اون تابعی که هر crate از نوع *binary* تو Rust باید حتماً تعریفش کنه چیه؟ اگه این درس به جای اون، یه crate از نوع *library* بود (مثل همون بخش‌های داخلی تو پوشه‌ی `/solution`) چه اتفاقی می‌افتاد — بازم به همچین تابعی نیاز داشت؟
2. `println!` یدونه علامت `!` داره. این بهت چی می‌گه و چه‌کاری می‌تونه انجام بده که یه تابع معمولی از پسش برنمیاد؟
3. اگه از عمد فرمتِ رشته رو تو `main.rs` خراب کنی (مثلاً `{}{}` بذاری ولی فقط یدونه آرگومان بهش بدی) چه خطایی می‌گیری؟ این خطا تو چه مرحله‌ای خودش رو نشون می‌ده — کامپایل یا اجرا؟
4. فایل `main.rs` میاد `p0_05_hello_rust::describe_journey` رو صدا می‌زنه. با توجه به اینکه فایل `Cargo.toml` اون crate میگه `name = "p0-05-hello-rust"` (با خط فاصله)، این اسم `p0_05_hello_rust` از کجا اومده؟
