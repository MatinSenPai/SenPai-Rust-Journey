# راه‌حل — سلام، Rust

```rust
pub fn describe_journey(language: &str, day: u32) -> String {
    format!("Day {day} of learning {language}: still compiling.")
}
```

ماکروی `format!` دقیقاً مثل `println!` کار می‌کنه با این تفاوت که به جای اینکه مقدار رو چاپ کنه، یه `String` برمی‌گردونه — همون placeholders که تو زمان کامپایل به‌وسیله‌ی ماکرو چک می‌شن (`{day}`، `{language}` — این سینتکس «قرار دادن مستقیم متغیر با اسمش داخل آکولادها» یکی از امکانات مدرن و راحتی‌های زبانه؛ البته ممکنه سبک قدیمی‌ترش رو با آرگومان‌های موقعیتی، یعنی با استفاده از `{}` ببینید، مثلاً `format!("Day {} of learning {}", day, language)`، که دقیقاً همون کار رو می‌کنه و همچنان یه روش کاملاً استاندارد به حساب میاد، مخصوصاً وقتی که اون مقدار فقط یه اسم متغیر ساده نیست).
