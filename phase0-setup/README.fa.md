# فاز صفر — راه‌اندازی و جهت‌یابی

قبل از اینکه با اولین خطای بررسی‌کننده‌ی قرض روبه‌رو شوی، جهت‌یابی کن: اینکه زبانِ کامپایلی واقعاً یعنی چه، یک زنجیره‌ابزارِ سالم، اولین برنامه‌ات، و عادتِ خواندنِ چیزی که کامپایلر بهت می‌گوید.

هفت درس، بیشترشان خواندنی. با این حال عجله نکن — مدلِ ذهنیِ درسِ ۱ در تمامِ مسیر خرجش را در می‌آورد، و درسِ ۵ همان چیزی است که تعیین می‌کند ماهِ اولت با Rust خسته‌کننده باشد یا جذاب.

| # | درس | برای چه |
|---|---|---|
| ۱ | [زبان کامپایلی یعنی چه؟](01-what-is-a-compiled-language/README.fa.md) | چرا Rust چیزهایی را می‌گیرد که پایتون نمی‌گیرد، و بابتش چه می‌دهی |
| ۲ | [نصبِ Rust و زنجیره‌ابزارها](02-installing-rust-and-toolchains/README.fa.md) | `rustup`، کانال‌ها، ویرایش‌ها، و لینکرِ ویندوز |
| ۳ | [سلام Rust](03-hello-rust/README.fa.md) | اولین برنامه‌ات: `fn`، `println!`، و اینکه تابع چطور مقدار برمی‌گرداند |
| ۴ | [مبانی Cargo](04-cargo-basics/README.fa.md) | ابزاری که هر روز می‌زنی، و اینکه `Cargo.toml` چه می‌گوید |
| ۵ | [خواندنِ خطاهای کامپایلر](05-reading-compiler-errors/README.fa.md) | پرارزش‌ترین مهارتِ این فاز |
| ۶ | [ابزارها: clippy، fmt، rust-analyzer](06-tooling-clippy-fmt-rust-analyzer/README.fa.md) | فراتر از «کامپایل می‌شود»، تا «Rustِ خوبی هست؟» |
| ۷ | [گیت و گردشِ کارِ مخزن](07-git-and-repo-workflow/README.fa.md) | چطور در ماه‌های پیشِ رو گم نشوی |

ترتیبش عمدی است: اول یک برنامه را اجرا می‌کنی (۳) و بعد ابزارِ اجرا کننده‌اش را می‌خوانی (۴)، و اول کد می‌نویسی (۳) و بعد یاد می‌گیری خطاهایی را که تولید می‌کند بخوانی (۵). هیچ‌کدام برعکس جواب نمی‌دهد.
