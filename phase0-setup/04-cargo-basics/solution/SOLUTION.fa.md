# راه‌حل — ۰۴ مبانی Cargo

```rust
pub fn format_greeting(name: &str, times: u32) -> String {
    let one = format!("Hello, {name}!");
    vec![one; times as usize].join("\n")
}

pub fn pick_encouragement() -> String {
    let lines = [
        "Keep going.",
        "One todo!() at a time.",
        "You've got this.",
    ];
    lines[rand::random::<usize>() % lines.len()].to_string()
}
```

## `format_greeting` — چند جوابِ درست دارد

سه شکلی که معمولاً سراغشان می‌روند:

```rust
// رشته را یک بار بساز، n بار کپی کن، به هم بچسبان
let one = format!("Hello, {name}!");
vec![one; times as usize].join("\n")

// با پیمایش یک وکتور بساز
(0..times).map(|_| format!("Hello, {name}!")).collect::<Vec<_>>().join("\n")

// دستی توی یک رشته push کن
let mut out = String::new();
for i in 0..times {
    if i > 0 { out.push('\n'); }
    out.push_str(&format!("Hello, {name}!"));
}
out
```

هر سه پاس می‌شوند. اگر سومی را نوشته‌ای ناراحت نباش — بدیهی‌ترین راه برای کسی است که از پایتون می‌آید، و دقیقاً همانی است که clippy در درسِ ۰۶ ازش دورت می‌کند.

اولی اینجا ترجیح دارد، به یک دلیلِ مشخص: `format!` را **یک بار** صدا می‌زند. دومی `times` بار صدایش می‌زند و هر بار همان رشته را از نو قالب‌بندی می‌کند. روی سه احوال‌پرسی کسی متوجه نمی‌شود. روی سی هزار تا، این تفاوتِ بینِ یک حلقه‌ی تخصیص‌وکپی و سی هزار عملیاتِ قالب‌بندی است.

دیدنِ همین نکته از یاد گرفتنِ نحو ارزشمندتر است. `format!` مجانی نیست.

آن `times as usize` یک تبدیل (cast) است — `vec![value; n]` برای تعداد `usize` می‌خواهد و تو `u32` داری. تبدیل‌ها حالت‌های لبه دارند (فاز ۱ می‌گویدشان)؛ این یکی امن است چون `u32` روی هر پلتفرمی که این دوره هدف گرفته، همیشه در `usize` جا می‌شود.

## `pick_encouragement` — نکته‌اش وابستگی بود

منطقش عمداً بی‌اهمیت است. چیزی که مهم بود:

۱. `rand` باید در `Cargo.toml` می‌بود تا `rand::random` اصلاً پیدا شود.
۲. باید می‌فهمیدی چطور صدایش بزنی — ترجیحاً از راهِ `cargo doc --open` نه جستجوی وب.

`rand::random::<usize>()` به آن ترفندِ `::<usize>` نیاز دارد چون `random` روی نوعِ خروجی‌اش جنریک است و هیچ‌چیز اینجا به کامپایلر نمی‌گوید کدام نوع را می‌خواهی. اگر بنویسی `let x: u8 = rand::random();` همان اعلانِ نوع این را تأمین می‌کند. هر دو کار می‌کنند؛ جنریک‌ها فاز ۲ هستند.

`% lines.len()` هر عددی را روی یک ایندکسِ معتبر می‌نشاند. کمی به‌سمتِ عناصرِ اول اریب است — برای انتخابِ یک جمله‌ی دلگرم‌کننده کاملاً بی‌اهمیت. برای هر جایی که انصاف مهم است (بُر زدنِ کارت، نمونه‌گیری) از خودِ کمک‌کننده‌های `rand` استفاده کن که درست مدیریتش می‌کنند.

## این درس واقعاً درباره‌ی چه بود

نه این دو تابع. درباره‌ی این‌ها بود:

- خواندنِ `Cargo.toml` و دانستنِ کارِ هر بخشش.
- `cargo add` و `cargo tree`، تا وابستگی جادو نباشد.
- دانستنِ اینکه `Cargo.lock` وجود دارد و کِی کامیتش می‌کنی.
- `cargo check` در برابر `cargo build`، و اینکه چرا سراغِ اولی می‌روی.

اگر تا آخرِ درس، `cargo new` و `cargo add` در یک پوشه‌ی موقت برایت عادی شده بود، همان نتیجه‌ای است که اهمیت دارد.
