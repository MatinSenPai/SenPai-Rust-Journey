# ایست بازرسی — ابزار‌ها

1. دو warning را انتخاب کن و توضیح بده چرا نسخه‌ی اولیه ضعیف‌تر بود، نه فقط اینکه چه تغییری دادی.
2. چرا clippy برای تابع فقط‌خواندنی `&str` را به `&String` ترجیح می‌دهد؟
3. فرق تصمیم تو با کاری که `cargo clippy --fix` خودکار انجام می‌دهد چیست؟
4. روی نسخه‌ی پاک `cargo fmt -- --check` را اجرا کن. مسئولیت `rustfmt` و `clippy` چگونه تقسیم شده است؟
